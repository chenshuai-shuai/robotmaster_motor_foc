**本次（v0.1.52-dev）改动的重点在哪 —— 三句话版**：
1. **控制路径全换**：以前"按键长按 → 发使能帧 → 发阻尼帧保持"，现在**只有串口 `#` 命令能动电机**；A 板变成外环控制器（位置 PD / 速度 PI+前馈 / 力矩 / 阻抗），200Hz 出 MIT 帧。
2. **口径纠正（8 倍坑）**：本电机是**双编版**，`POS/VEL` 是**输出端**（`PMECH=±12.56 rad`），不再除减速比 8。屏/日志/协议/外环**全走同一张常量表**（`motor_8108.h` 的 `J8108_SCALE_OUTPUT_SIDE`）。
3. **安全与可观测**：使能/失能/零点/清错都走"发帧 → 等 20ms → 查 ACK → 无 ACK 主动丢帧"；心跳 200ms 无命令自动退阻尼（**不失能**）；`@EVT` 事件流 + `@TEL` 遥测 + 屏 4 页。

**换版本后最少要跑的项**：`SMK-01~05`（3 分钟）+ 本次改动涉及的层。已知**从未在实机验证过**的项在 §7 标 `M!`。

### 2.4 台架模式与调参顺序（⭐ 每次动速度/位置模式前先看这段）

**心跳语义（先搞清这个，否则会误判"电机不转"）**：`#V/#P/#T/#IMP` 设的是**目标**，不是"一直跑"。
`wd=200ms` 内没有**任何新命令** → 自动退 `DAMP`（日志 `EVT TIMEOUT: no command for 200ms`）= **设计行为**（防上位机失联）。

| 想做什么 | 怎么做 |
|---|---|
| 台架手动试转（一次一条命令） | 先 `#WD 0`（关心跳看门狗）→ 再 `#V 5`…；收尾 `#WD 200` 复原 + `#STOP` |
| 保持心跳保护（真实机器人） | 上位机每 ≤100ms 发一条命令（`#PING` 或重发目标） |
| 脚本化测试 | `tools/serial_bench.py` 可循环发命令（`--interactive` 手发也行，但记得手动维持心跳） |

**速度模式调参顺序（抖动 → 稳转）**——小惯量直驱关节必须"从小往上"，**别一上来就 #V 20**：
```
#EN                 -> @OK EN mode=DAMP frames=ON
#WD 0               -> 台架模式：不因心跳超时中断
#LIM T 1            -> 先把力矩上限压到 1 N·m（防猛抖，安全网）
#SET KP_V 0.002     -> 从小增益起（默认已是 0.005）
#SET KI_V 0.0002
#V 5                -> 5 deg/s 慢转：应平稳、方向正确
（好） #SET KP_V 0.005 → #V 10 → 观察跟随偏差
（抖） #SET KP_V 0.001 或 #SET TRATE 5（更慢的力矩斜率）
#STOP / #WD 200      -> 收尾
```
**判据**：起步平滑（无"猛抖一下"）、`@TEL` 的 `vel` 接近目标、力矩不长期贴 `tmax`、不再出现成片的 `@EVT LIMIT`。

**为什么不能用"大 Kp 硬顶"**：关节惯量小，200Hz（5ms）下 `T/dt` 造成速度变化 = `(T/J)·dt`；
`kp_v=0.05` 时 20 dps 误差 → 1 N·m → 一周期就把关节推过头 → 反向饱和 → **极限环**（抖）。
`trate_nm_s` 限制"每周期力矩增量"就是把这个环路变成"慢而稳"。

### L0 冒烟（每次烧录后 3 分钟必做，⭐3）

**SMK-01 启动横幅齐全**
- 步骤：断电→上电，抓串口前 3 秒输出。
- 预期（标签/文字需能对上，时间戳可有）：
```
[J8108] I: 8108 joint motor control task | FW v0.1.52-dev | proto v1 (serial-driven)
[J8108] I: SCALE = OUTPUT-SIDE (dual-encoder doc): pos/vel are joint-side, NO /8. pmax=12.56rad(720deg) vmax=45 tmax=18.0 dir=+0
[J8108] I: CAN init OK (rx_id=0x781 registered, controller started) -> display: CAN INIT OK / WAITING
[J8108] I: ctrl: CAN1 1Mbps | cmd 0x001 | MIT 0x201 | FB 0x781 | 200Hz frames | wd=200ms
[J8108] I: limits: p[-170..170]deg vmax=300dps tmax=7.5Nm rate=3000dps2 | gains kd_damp=1.00 kp_pos=20.0 kd_pos=1.00 kp_v=0.050 ki_v=0.0020
[J8108] I: SAFETY: enable via serial #EN only (no local button action). watchdog 200ms -> DAMP (not disable). PB2 = UI only
[cmd] I: serial protocol v1 listener up: #CMD -> @OK/@ERR (log lines are separate)
[Monitor] I: task up: screen 10Hz / log 1Hz / telemetry(period=0ms) - all from the SAME snapshot
[Monitor] I: pages: 0=LINK 1=MOTION 2=SERIAL 3=SYSTEM | key: click=next dbl=prev hold=home (UI ONLY, no motor action)
```
- 失败排查：缺 `[J8108]` 行 → CAN 任务未建（看 `xTaskCreate FAILED` / heap）；缺 `[Monitor]` → 屏/监控任务未建；全无输出 → 串口线/波特率/USART6 接错。

**SMK-02 无 CAN 节点时不误报使能**
- 步骤：不接电机（或电机不上电），发 `#EN`。
- 预期：`@ERR 5 EN no ACK on bus: check 24V / CAN_H-L / 120R / CANID`；日志 `no ACK in 20ms -> TX aborted...`。**电机保持未使能**（屏 P1 `EN 0`）。
- 失败排查：若回了 `@OK EN ...` → 说明总线有节点在应答（或 CANID 撞车），先查接了什么设备。

**SMK-03 状态查询**
- 步骤：发 `#STAT`。
- 预期（未使能/未收到过反馈时，v0.1.55 起）：
```
@OK STAT link=DOWN mode=IDLE en=0 rx=0 tx=0 age=never hold=0 set=0.00 (values withheld: no fresh frame)
```
  使能且反馈流起来之后：
```
@OK STAT link=UP mode=DAMP en=1 pos=.. vel=.. T=.. Tm=.. Tr=.. err=0x00 rx=.. tx=.. age=5ms hold=1 set=0.00
```
  ⚠️ **绝不能**在无数据时看到 `pos=-719.64 vel=-2578.3 T=-18.000`（全 0 缓冲被解成量程最小值 = 假数据）。
- 说明：`age` 是"距最近一帧反馈的毫秒数"；`hold`=1 表示正在 200Hz 发帧。

**SMK-04 未知命令与参数错误**
- 步骤：依次发 `#FOO`、`#V 1.2.3`、`#V`、`#MODE NOPE`。
- 预期：
```
@ERR 1 FOO unknown command (try #HELP)
@ERR 2 V bad arguments
@ERR 2 V usage: #V <deg/s> [kd] [tff]
@ERR 2 MODE unknown mode
```
- 失败排查：`#V 1.2.3` 若回 `@OK ...` → 解析器退化（应把"数字形状但非法"的 token 判为 `@ERR 2`）。

**SMK-06 CAN 必须注册成功（⭐3，v0.1.53 新增——上次就是这里断的）**
- 步骤：上电抓启动日志前半段。
- 预期：**必须有** `[J8108] I: CAN init OK (rx_id=0x781 registered, controller started) -> display: CAN INIT OK / WAITING`；
  **绝不允许**出现 `[J8108] E: CAN status -> INIT FAIL`、`[J8108] E: CAN init FAILED (CANRegister returned NULL)`。
  屏 P0 行0 应为 `LINK 1/4 INIT OK WAIT`（未接电机时）而不是 `INIT FAIL`。
- 失败排查：`INIT FAIL` 说明 `J8108_Init(&hcan1)` 没被调用（本地初始化问题，**不是**接线问题）；对照 `tools/verify_dev.py` 的"接线: J8108_Task_Init 必须调用 J8108_Init"断言。

**SMK-07 串口发命令必须回包（⭐3，v0.1.53 新增——上次就是这里断的）**
- 步骤：串口助手**务必勾选"发送新行/追加回车换行（\\r\\n）"**，发 `#PING`；或直接用 `python tools/serial_bench.py --port COM3 --cmd "#PING"`（自动加换行）。
- 预期：回 `@OK PING ms=<数字>`；日志（前 3 条命令）出现 `[cmd] I: rx line 1: "#PING"`；屏 P2 行2 `RX 1L 6B TX 1L` 自增。
- 失败排查（三步定位）：
  - 屏 P2 `RX 0L 0B` 且发命令无任何反应 → **字节根本没进来**：查 USB-TTL 是否接 USART6(TX=PG14/RX=PG9)、是否接了 RX、波特率/编码、串口号是否选对。
  - `RX 0L` 但 `nB` 在涨 → **字节进来了但没形成一行**：终端没加换行（勾"发送新行"），或只发了 CR（v0.1.53 起 CR 也算行结束，重烧后再试）。
  - `RX nL` 在涨但没回包 → 解析层问题：把 `[cmd] I: rx line …` 原文发我。

**SMK-09 无数据时 `#STAT` 不打数值（⭐3，v0.1.55 新增）**
- 步骤：电机不上电（或未接），发 `#STAT`；屏翻到 `LINK 1/4` 看 AGE 行。
- 预期：`@OK STAT link=DOWN ... age=never ... (values withheld: no fresh frame)`；屏显 `AGE never  LINK DOWN`。
- 失败排查：若打印 `pos=-719.64` / `vel=-2578.3` / `T=-18.000` → 假数据门控失效（那是量程最小值 = 全 0 缓冲解算结果）。

**SMK-10 崩溃黑匣子（⭐3，v0.1.57 新增）**
- 步骤：正常上电，看开机前几行。
- 预期（没崩过）：`[fault] I: black box: clean (no crash recorded since power-on)`
- 预期（上次崩过）：`[fault] E: PREVIOUS RUN CRASHED: HardFault ... PC=0x... LR=0x... CFSR=0x...` 或 `... STACK OVERFLOW in task '<名字>' ...`
- ⚠️ **崩溃后要按【复位】而不是断电**（备份寄存器掉电会清）；断了电就只能在 Keil 里 Stop 后看 `s_hf_pc` / `s_overflow_task`（不复位直接看）。

**SMK-11 栈裕量自报（⭐2，v0.1.57 新增）**
- 步骤：上电 5 秒后看日志。
- 预期：三条 `[J8108]/[cmd]/[Monitor] I: stack headroom: N words free of M (must stay well above 0)`；N 应远大于 0（经验：剩余 <20% 就该加大该任务栈）。
- 失败排查：某任务 N 很小（个位数）→ 把该任务 `*_TASK_STACK_WORDS` 加大后重编。

**SMK-12 协议口没被锁死（⭐2，v0.1.57 新增）**
- 步骤：跑一会儿，看每 10s 的 `[Monitor] I: summary: ... txdrop=0`。
- 预期：`txdrop=0`；若 >0 说明有写入方取锁超时（被卡过），应把当时的日志发我。

**SMK-13 控制循环没被饿死（⭐3，v0.1.59 新增）**
- 步骤：跑 1 分钟，看每 10s 的摘要行。
- 预期：`... txdrop=0 dtmax=<个位数>ms`。
- 失败排查：`dtmax` 出现 100ms 级 → 控制任务被长阻塞/抢不到 CPU（查是否有长自旋、日志风暴、总线卡死）；`txdrop>0` → 协议口曾被占住。
  **注意**：只有这两项正常，才能说"板子没饿死"；否则"无回包"可能是饿死而非崩溃。

**SMK-05 一键核验（PC 侧）**
- 步骤：`make verify`。
- 预期：`共 56 项，失败 0 项 -> ALL PASS`，且 `0 Error(s), 0 Warning(s)`。
- 失败排查：见输出里 FAIL 行的 detail。

### L1 界面 / 按键（不接电机也能测，⭐2）

**UI-01 四页可翻（⭐3）**
- 步骤：单击 → 单击 → 单击 → 单击；再双击一次；再长按 ≥2s。
- 预期：屏行0 依次 `LINK 1/4` → `MOTION 2/4` → `SERIAL 3/4` → `SYSTEM 4/4` → 单击回到 `LINK 1/4`；双击回上一页；长按回 `LINK 1/4`。日志：`[Monitor] I: key: page -> 2/4` / `key: page -> home (1/4)`。
- 失败排查：完全无反应 → PB2 接线/`KEY_ACTIVE_LEVEL`（A 板高有效）；跳两页 → 单击被识别成双击（阈值问题，记录现象）。

**UI-02 按键绝不动电机（⭐3，安全）**
- 步骤：接电机上电 → `#EN`（进入 DAMP，轴有阻尼）→ **狂点/长按按键 10 次**。
- 预期：电机状态**完全不变**（屏 P1 `EN 1 / SEND 1` 不变、`@TEL` 流不断、轴阻尼手感不变）；串口只有 `key: page ->` 日志，**没有任何 `@EVT ENABLED/DISABLED`**。
- 失败排查：若出现使能/失能事件 → 严重回退，立即停机排查（按键不得触碰电机是硬约束）。

**UI-03 各页数值正确（⭐2）**
- 步骤：`#EN` 后逐页看 P1/P2/P3。
- 预期：
  - P1 `MOTION`：`POS`/`VEL`/`T`/`Tm`/`Tr` 有真实值；`AGE` 小（个位 ms）；`KP 20.0 KD  1.00`。
  - P2 `SERIAL`：`LAST #<命令>`、`RX/TX lines` 递增、`WD LEFT` 在 0~200 之间跳动、`TEL 50ms`（若已开）。
  - P3 `SYSTEM`：`FW v0.1.52-dev`、`HEAP` ≈2 万 B、`TASKS 6`、`PMAX 720 deg`。
- 失败排查：`PMAX` 显示 180 → 口径回退成单编；数值空 `----` → `age>200ms`（链路断，属正常降级）。

**UI-04 数据不新鲜时只报 LINK DOWN（⭐2，需求回归）**
- 步骤：电机断电（A 板仍上电），看 P0/P1 与串口 1Hz 日志。
- 预期：`AGE xxx ms  LINK DOWN`，P1 数值位显示 `----`；日志：
```
[Monitor] I: summary: link=DOWN (no fresh frame for 1234ms) mode=DAMP en=1 rx=... tx=... | stale values not printed on purpose
```
  绝不出现"旧数值照打"的情况。
- 失败排查：仍打印数值 → 新鲜度门控被改坏。

**UI-05 局部刷新不闪屏（⭐1）**
- 步骤：静止时盯着屏 10 秒。
- 预期：画面稳定不闪、不整屏跳动；只有变化的数字在变。
- 失败排查：整屏闪 → 局部刷新逻辑被破坏（每次都全刷）。

**UI-06 P2 页协议诊断可读（⭐1，v0.1.53 新增）**
- 步骤：翻到 `SERIAL 3/4`，发任意命令。
- 预期：行1 `LAST #<命令>`、行2 `RX nL mB TX kL`（L=解析成功的行数，mB=收到的原始字节，B 会先于 L 增长）。

### L2 协议连通（不接电机，⭐2）

**PRT-01 基本连通**
```
#PING   -> @OK PING ms=12345
#VER    -> @OK VER fw=v0.1.52-dev proto=1 u=deg,dps,Nm pmax=720 vmax=45 tmax=18 scale=output dir=+0 canid=0x01 ctrl=200Hz
#HELP   -> @OK HELP cmd=PING,VER,STAT,LOG,CLR,SET,GET,EN,DIS,... （共 2 行）
```
- 关键：`scale=output`（双编口径）；`pmax=720`。若 `scale=motor` → 口径判错。

**PRT-02 日志静音开关**
- 步骤：`#LOG 0` → 触发一次 `#PING` → `#LOG 1`。
- 预期：`#LOG 0` 后串口**只剩 `@` 行**（不再有 `[tag] I:`）；`#LOG 1` 后恢复事件级日志。

**PRT-03 参数读写（⭐2）**
```
#GET            -> 3 行：@OK GET gains ... / @OK GET limits ... / @OK GET misc ...
#SET kd_damp 1.5 -> @OK SET KD_DAMP=1.500
#GET            -> kd_damp=1.500
#SET kp_pos 600 -> @ERR 2 KP_POS outside motor range   （Kp≤500）
```
- 说明：`#GET` 故意拆 3 行（协议单行 ≤127 字节，防截断）。

**PRT-04 限制设置（⭐2）**
```
#LIM              -> @OK LIM pmin=-170.0 pmax=170.0 vmax=300 tmax=7.50 rate=3000 wd=200
#LIM P -90 90     -> @OK LIM P min=-90.0 max=90.0
#LIM P 90 -90     -> @ERR 2 LIM min must be < max
#V 0              -> @ERR 3 V not enabled (send #EN first)     （未使能时任何运动命令都拒；用 #V 0 而非 #P/#T，避免误动）
```
> ⚠️ 想验证"已使能状态下运动命令被接受"时**才**发 `#P`/`#T`；不确定电机是否已使能时，先 `#STAT` 看 `en=`，或用 `#V 0` 代替（永远安全）。自动冒烟脚本 `--smoke` 只用 `#V 0`。

**PRT-05 遥测**
```
#TEL 50   -> @OK TEL period=50ms   （之后每秒 20 行 @TEL）
#TEL 1    -> @TEL ms=... mode=... en=... pos=... vel=... T=... Tm=... Tr=... err=0x00 set=... age=...  + @OK TEL once
#TEL 0    -> @OK TEL period=0 (off)
```
- 判据：`@TEL` 的 `age` 应稳定在**个位 ms**（正常 200Hz 回传）；`age` 持续增大 → 反馈断了。

**PRT-06 危险命令防线（⭐3，安全）**
```
#ZERO                     -> @ERR 4 ZERO persistent! resend as `#ZERO CONFIRM` (writes motor zero, survives power-off)
#SETP 0 0 0 0 0.5         -> @ERR 4 SETP locked: use `#SET SETP 1` to unlock (raw motor units, no clamping)
```
- 说明：这两条是"会改硬件状态/绕过限幅"的命令，**默认锁死**。测试时**不要**执行 `#ZERO CONFIRM` 与解锁后的 `#SETP`（见 L5 可选）。

**PRT-07 心跳续命（⭐2）**
- 步骤：`#EN`（若已接电机）或未使能下连续发 `#PING` 每 100ms。
- 预期：`#STAT` 的……未使能时无超时行为；使能后见 MTR-08。命令本身每次都回 `@OK PING ms=...`，不丢包。

**PRT-08 行长度/换行容错**
- 步骤：发送**只带 `\n`**（不追加 `\r`）的命令；发送一条 200 字符的超长行。
- 预期：前者正常工作；后者回 `@ERR 2`（行太长）并**后续命令仍正常**（不能把协议卡死）。

### L3 电机基本（接 24V；⭐3）

**MTR-01 上电与 CAN 建链**
- 步骤：电机 24V 上电、120Ω 打开，观察 P0 `LINK` 页与日志。
- 预期：A 板侧 `CAN status -> INIT OK / WAITING for node`；电机上电后只要开始回帧 → `CAN feedback link UP (rx=...)`。**注意**：本电机是"一发一收"响应式心跳，A 板不发帧时电机不主动回传 → 未 `#EN` 前 `rx=0` 是**正常**的。

**MTR-02 使能（⭐3）**
```
#EN
-> @OK EN mode=DAMP frames=ON
-> @EVT ENABLED mode=DAMP
日志：-> ENABLE frame (0x001 id, data ...FC) | wait 20ms for ACK
      ENABLE ok -> mode=DAMP, control frames ON (200Hz) -> feedback should stream now
屏 P0：MODE DAMP EN 1 ／ P1：EN 1 SEND 1
```
- 失败：`@ERR 5 EN no ACK on bus...` → 查 24V / CAN_H-L 是否接反 / 120Ω / CANID；`@ERR 8 EN timeout` → 控制任务忙（不该出现，记录）。

**MTR-03 反馈流 200Hz（⭐3）**
- 步骤：`#TEL 50`，观察 5 秒；再 `#STAT`。
- 预期：`@TEL` 每秒约 20 行，`age` 个位 ms，`rx` 持续增长；`#STAT` 的 `hold=1`。屏 P0 `AGE 5ms  200Hz`。
- 判据：**rx 增长 ≈ tx 增长（1:1，响应式）**。
- 失败：`rx` 不涨 → 电机未真使能/掉线（看 `@EVT LINKLOST`）。

**MTR-04 阻尼手感（⭐3，安全确认）**
- 步骤：手拧输出轴，慢拧再快拧；松手观察。
- 预期：**有阻力、速度越快阻力越明显（T ≈ −Kd·v）、松手停住不回弹、不漂移、无嗡嗡自激**。
- 失败：完全无阻力（可能未使能）／自激抖动（Kd 过大）／发热明显 → 记录并停机。

**MTR-05 失能与急停（⭐3，安全）**
```
#STOP   -> @OK STOP mode=DAMP (still enabled) + @EVT STOP mode=DAMP   （保持使能=防坠，轴仍有阻尼）
#ESTOP  -> @OK ESTOP mode=DISABLED (shaft FREE) + @EVT ESTOP mode=DISABLED
#EN     -> 重新使能（@EVT ENABLED）
```
- 预期：`#ESTOP` 后**输出轴自由**（可轻松转动）；`#EN` 可恢复。
- ⚠️ 该电机**无抱闸**：`#ESTOP` 后关节会自由下垂，务必托住。

### L4 控制功能（接 24V、空载台架；⭐3）

**MTR-06 速度模式（按 §2.4 流程，⭐3）**
```
#EN
#WD 0                 （台架模式）
#LIM T 1              （安全网：力矩 ≤1 N·m）
#SET KP_V 0.002
#V 5
```
- 预期：`@OK V target=5.00 dps mode=SPEED`；输出轴**平稳**缓转（不抖）；`@TEL` 的 `vel` 逐步贴近 5；方向与 `vel` 符号一致；
  若贴住力矩上限会看到**一次** `@EVT LIMIT what=torque`（不是成片刷）。
- 失败排查：
  - **猛抖一下**（历史现象）→ 增益仍偏大：`#SET KP_V 0.001` 或 `#SET TRATE 5`；同时确认没把 `#LIM T` 放开。
  - **完全不转** → ① 是否 200ms 后 `@EVT TIMEOUT`（没 `#WD 0` 又没续命令）② `#STAT` 看 `en=1 mode=SPEED` 与 `T` 是否非 0 ③ `Tm/Tr` 与供电。
  - **转一下就停** → 心跳超时（见上）或 `#LIM P` 把位置限死（位置模式下）。
- 通过后再逐步加大：`#SET KP_V 0.005` → `#V 10`，观察到位/跟随；收尾 `#STOP` + `#WD 200`。

**MTR-07 位置模式（小角度）**
```
#P 10            -> @OK P target=10.00 deg mode=POS kp=20.0 kd=1.00
（观察）          -> 轴平滑转到 10°，停稳（屏 P1 INPOS 1），无过冲震荡
#P -10           -> 转回 -10°
#HOLD            -> @OK HOLD mode=DAMP（回阻尼保持）
```
- 重点验证（本次最关键的回归点）：**是否从当前位置平滑起步**（历史 bug：切模式未预置设定点 → 从 0° 猛冲）。判据：起步时**没有**"突然一顿/弹一下"。
- 失败：若出现猛冲/异响 → 立即 `#STOP`/断电，记录当时的 `#STAT` 与屏 P1；这是最高优先级缺陷。

**MTR-08 心跳超时（⭐3，安全）**
- 步骤：`#V 20` → **停止发任何命令** 1 秒。
- 预期：约 200ms 后
```
@EVT TIMEOUT mode=DAMP
[J8108] W: EVT TIMEOUT: no command for 2xxms -> back to DAMP (motor stays ENABLED)
```
  电机**退阻尼但保持使能**（`#STAT` `en=1 mode=DAMP`），轴不会自由掉落；再发命令即可继续。
- 失败：`en` 变 0（不该失能）／完全不超时（心跳门控失效）。

**MTR-09 掉线 → 自动恢复（⭐3）**
- 步骤：`#EN`（阻尼中）→ 拔掉电机 24V → 观察 ~1 秒 → 插回。
- 预期（拔掉）：
```
[J8108] W: TX not ACKed (mailbox stuck ...) -> aborted; check 24V/CAN_H-L/120R/CANID
@EVT LINKLOST what=noack      （或 what=nofb）
[J8108] W: link lost (no ACK) -> will retry ENABLE in 500ms (1/4)
```
  插回后最多 4 次退避重试（0.5s/1s/1.5s/2s）→ `@EVT ENABLED mode=DAMP` 并恢复 200Hz 流；日志 `link healthy again (rx=...) -> failure counter reset`。
- 失败：不恢复 → 看是否已 `give up retrying`（发 `#EN` 手动重试）；恢复后**不自发运动**（DAMP 零力矩）是硬要求。

**MTR-10 状态一致性（⭐2）**
- 步骤：对比同一时刻的屏 P1、1Hz 日志、`@STAT`。
- 预期：三者数值**同源一致**（允许毫秒级差 1 个周期）；日志每 1 秒一行 `[Monitor] I: data: pos=...deg vel=...dps T=...Nm Tm=... Tr=... err=0x00 mode=... en=... set=... age=...ms`。

---

**MTR-14 静摩擦补偿（⭐3，v0.1.60 新增）**
- 前置：`#EN` → `#WD 0` → `#LIM T 2` → `#SET TRATE 20` → `#SET KI_V 0.02`
- 步骤：先不带前馈 `#V 10`，记录「从发命令到轴开始转」的时间与 `T` 峰值；`#V 0` 停；再 `#SET TFF 0.15` → `#V 10` 观察。
- 预期：带前馈后**起步 ≤1 秒**、起步抖动明显减小；`vel` 纹波变小；`T` 稳态≈`TFF` 附近（PI 只补差值）。
- ⚠️ **固件 gating**：`#SET TFF` 需 **≥v0.1.60-dev**（旧固件回 `@ERR 2 SET unknown key`）→ 旧固件用 `#V <dps> <kd> <tff>` 第 3 参等价测试。
- **附加实验（内环阻尼）**：对比 `#V 10 1.0 0.15` 与 `#V 10 0.3 0.15` → 若后者 `T` 中位数明显下降、纹波变小，说明电机内部阻尼（`T=−KD_DAMP×v`）是速度模式的主要阻力之一 → 速度模式用 `KD_DAMP 0.2~0.5`。
- 失败排查：仍不起步 → `TFF` 加大（如 0.2）；反向（`#V -10`）若顶住不动 → 前馈符号逻辑坏了（应为负号）。
- 记录：静摩擦（挣脱时 T 峰值）、动摩擦（稳态 T 中位数）、起步时间 —— 后面带负载调参要用。

**MTR-11 事件不洪泛（⭐3，v0.1.54 新增）**
- 步骤：制造一个"持续为真"的受限状态（如 `#LIM T 1` 后 `#SET KP_V 0.05` 再 `#V 20`），观察 2 秒。
- 预期：`@EVT LIMIT what=torque|trate` **只出现一次**（进入夹紧的那一刻）；期间不能刷屏。
- **抖动场景（v0.1.55 重点）**：调大 `#SET KP_V 0.01` 后若斜率限制时紧时松，事件**仍不得重报**（消退去抖：需连续 1s 不夹紧才允许再报）。
- 失败排查：成片刷 → 事件边沿锁存被改坏（每周期重报），回看 `ctrl_lim_update()`。

**MTR-12 力矩不一步跳变（⭐2，v0.1.54 新增）**
- 步骤：`#T 1`（力矩模式，需先 `#EN`，注意空载会转）。
- 预期：力矩从 0 **斜坡**上升到 1 N·m（20 N·m/s → 约 50ms），不是瞬间给满；`#STAT` 的 `T` 逐周期变化。
- 失败排查：一步到位 → `trate_nm_s` 失效（`#GET` 看 `trate=`）。

### L5 保护与边界（可选，⭐2）

**PROT-01 堵转（手捏输出轴 + `#V 20`）** → 1 秒后 `@EVT STALL mode=DAMP`，日志 `EVT STALL: high torque + low speed -> DAMP`。
**PROT-02 软限位（`#LIM P -30 30` → `#P 90`）** → 目标被夹到 30°，出现 `@EVT LIMIT what=setpoint`；`#STAT` `set=30.00`。
**PROT-03 过温**（长时间运行） → `Tm/Tr` 上升；>70℃ 预警 `@EVT TEMP ...`，>85℃ 自动 DAMP。**别故意加热**，观察即可。
**PROT-04 电机报错位** → `#ERR` 位非 0 时 `@EVT ERR=0xNN what=...`；`#CLR` → `@OK CLR done` + `@EVT CLRERR err=0x00`。
**PROT-05 零点（⚠️ 慎用）** → `#ZERO` 回 `@ERR 4 ...`；**仅当确认要改机械零点时**才 `#ZERO CONFIRM`（`@OK ZERO done` + `@EVT ZERO`）。零点**掉电保存**，改前先记录当前 `#STAT`。
**PROT-06 原始直通（⚠️ 慎用）** → `#SET SETP 1` 解锁后 `#SETP 0 0 0 1 0`（纯阻尼）；测试完 `#SET SETP 0` 并 `#HOLD`。此通道**不限幅**，仅用于诊断。

---

### L6 待定标（口径/端别，⭐3，未完成）

**EXP-01 口径判定（单编 vs 双编）**：读电机配置串口上电横幅（1Mbaud）记录协议版本与量程；或手拧输出轴 1 整圈，看 `#STAT` 的 `pos` 变化量：≈±720°→双编输出端（当前假设）；≈±90°→单编电机端。
- 若判定为**单编** → 改 `motor_8108.h` 的 `J8108_SCALE_OUTPUT_SIDE 0` 重编，并重跑 MTR-06/07。

**EXP-02 端别/方向**：`#V 20` 时记录轴的实际转向与 `vel` 符号是否一致；不一致则改 `J8108_DIR`（`+1.0f`/`-1.0f`）。

**EXP-03 力矩模式行为（⚠️ 空载危险）**：只有固定住负载时才测 `#T`；空载会持续加速。要确认"停机后电机是保持出力还是自行归零"时，用最小力矩（如 `#T 0.3`）并在 1 秒内 `#STOP`。

## §4 命令速查（可抄）

> **完整版"发什么字符串 → 收什么 → 电机做什么"见 `docs/1_规则（既定事实）/操作手册_串口命令.md`**（25 条命令 + 16 个 `#SET` 键 + 错误码/事件 + 照抄流程 + 危险命令清单）。
> 本节只列验收时最常用的几条。

| 命令 | 作用 | 备注 |
|---|---|---|
| `#PING` | 连通/心跳 | 回 `@OK PING ms=` |
| `#VER` | 版本+口径+量程 | 看 `scale=`/`pmax=` |
| `#STAT` | 一屏状态 | mode/en/pos/vel/T/Tm/Tr/err/rx/tx/age/hold/set |
| `#LOG 0|1|2` | 日志级别 | 0=只错误（联调推荐）；1=事件 |
| `#CLR` | 清电机报错位 | 0x001…FA |
| `#SET <k> <v>` / `#GET` | 参数读写 | `#GET` 回 3 行 |
| `#EN` / `#DIS` | 使能 / 失能 | 均查 ACK；失能=轴自由 |
| `#STOP` / `#ESTOP` | 阻尼急停 / 硬急停 | STOP 保使能；ESTOP 失能 |
| `#ZERO CONFIRM` | 写零点（持久） | ⚠️ 慎用 |
| `#MODE <IDLE|DAMP|SPEED|POS|TORQUE|IMP>` | 切模式 | 动作模式需先 `#EN` |
| `#DAMP [kd]` / `#HOLD` | 回阻尼 | 安全态 |
| `#V <dps> [kd] [tff]` | 速度目标 | 自动进 SPEED |
| `#P <deg> [kp] [kd]` | 位置目标 | 自动进 POS，带速率限制 |
| `#T <Nm>` | 力矩目标 | ⚠️ 空载会加速 |
| `#IMP <kp> <kd> [tff]` | 阻抗 | 参考角=进入时实际角 |
| `#LIM [P min max | V max | T max]` | 软限制 | 无参=回显 |
| `#RATE <deg/s²>` / `#WD <ms>` / `#TEL <0|1|ms>` | 速率/心跳/遥测 | `#TEL 1`=单次；`#WD 0`=关看门狗（台架） |
| `#SET TRATE <N·m/s>` | **力矩斜率上限** | 小惯量关节防抖关键；默认 20，0=不限（危险） |
| `#SETP p v kp kd t` | 原始 MIT 直通 | ⚠️ 需先解锁，不限幅 |
| `#HELP` | 命令表 | |

**错误码**：`1` 未知命令 · `2` 参数错/越界 · `3` 未使能 · `4` 模式不允许/已锁定 · `5` 电机报错或帧未 ACK · `6` 心跳超时 · `7` 软限位 · `8` 内部忙/超时
**事件**：`@EVT ENABLED/DISABLED/ZERO/CLRERR/MODE=<M>/TIMEOUT/STOP/ESTOP/LIMIT/FOLLOW/STALL/TEMP/ERR=<0xNN>/LINKLOST`

## §6 缺陷分级（怎么报给我）

| 级别 | 判据 | 处理 |
|---|---|---|
| **P0 安全** | 自发运动、猛冲、按键动了电机、失控、`#STOP`/`#ESTOP` 无效、心跳超时后仍出力 | 立即断电，**先别重试**，把日志+`#STAT` 发我 |
