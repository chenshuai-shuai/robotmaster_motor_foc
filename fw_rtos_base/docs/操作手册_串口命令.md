> 用途：**手敲/上位机发送时的对照表**。每条命令给出「发送字符串 / 回包（逐字）/ 实际动作 / 注意」。

## §1 30 秒上手

### 1.1 串口终端怎么设
| 项 | 值 |
|---|---|
| 端口 | USB-TTL 对应的 COM 口（日志与命令**同一个口**：USART6，TX=PG14/RX=PG9） |
| 波特率 | **115200**，8 数据位，无校验，1 停止位（8N1） |
| 换行 | **必须发换行**：勾"发送新行/追加 `\r\n`"。`\r`、`\n`、`\r\n` 三种都接受（v0.1.53+） |
| 编码 | ASCII 即可（命令全 ASCII） |
| 建议 | 先发 `#LOG 1` 或 `#LOG 0`，把 `[tag] I:` 日志压掉，只留 `@` 回包，看着最清楚 |
| 大小写 | **不敏感**（`#v 5` = `#V 5`）；行首必须是 `#` |

### 1.2 第一次用：照抄这 8 行
```
#PING
#VER
#STAT
#EN
#WD 0
#LIM T 1
#SET KP_V 0.002
#V 5
```
每行都会有一条 `@OK ...` 回包。全部走完 → 输出轴应**平稳慢转**（5°/s），手拧有阻力。
收尾：`#STOP`（停转、保持使能）→ `#WD 200`（恢复心跳保护）→ `#DIS`（彻底失能、轴自由）。
> ⚠️ 台架手动试转**必须先 `#WD 0`**，否则 200ms 没有新命令就自动退阻尼（见 §7.2）。

## §2 命令总表（速查：一条一行）

**系统/诊断**

| 发送 | 干什么 | 回包（示例） |
|---|---|---|
| `#PING` | 连通测试、心跳续命 | `@OK PING ms=12345` |
| `#VER` | 版本 + **口径 + 量程** | `@OK VER fw=v0.1.54-dev proto=1 u=deg,dps,Nm pmax=720 vmax=45 tmax=18 scale=output dir=+0 canid=0x01 ctrl=200Hz` |
| `#STAT` | 一屏状态（位置/速度/力矩/温度/错误/计数/数据年龄） | **有数据**：`@OK STAT link=UP mode=DAMP en=1 pos=-0.01 vel=-0.6 T=-0.013 Tm=40.0 Tr=29.4 err=0x00 rx=1234 tx=1234 age=5ms hold=1 set=0.00`
**无数据**（从未收到/超 200ms 未更新）：`@OK STAT link=DOWN mode=IDLE en=0 rx=0 tx=0 age=never hold=0 set=0.00 (values withheld: no fresh frame)` ← **故意不打数值**（rx=0 时缓冲全 0，解出来是量程最小值 -720°/ -2578°/s / -18N·m，看着像真数据） |
| `#LOG 0`\|`1`\|`2` | 日志级别：0=只错误 1=事件(推荐) 2/3=调试（含高频帧） | `@OK LOG lvl=1 (0=err 1=info 2/3=debug)` |
| `#CLR` | 清电机报错位（0x001…FA） | `@OK CLR done` + `@EVT CLRERR err=0x00` |
| `#ST` | **模块自检汇总**（非破坏性只读）：`disp`/`led`/`key`/`can`/`j8108`/`monitor` | `@OK ST disp=1 led=1 key=1 can=1 j8108=1 monitor=1`；任一模块 `3` → `@ERR 6 ST disp=3 ...` |
| `#ST <模块>` | 查单个模块 | `@OK ST can=1`；该模块本固件未编译 → `@ERR 9 ST module=disp code=255 (not compiled in this profile)` |
| `#HELP` | 命令表 | 3 行 `@OK HELP cmd=...` |
| `#GET` | 读全部参数（**回 3 行**） | `@OK GET gains ...` / `@OK GET limits ... trate=...` / `@OK GET misc ...` |

**使能 / 急停**

| 发送 | 干什么 | 回包 |
|---|---|---|
| `#EN` | **使能**（…FC）→ 成功后自动进阻尼并开始 200Hz 发帧 | `@OK EN mode=DAMP frames=ON` + `@EVT ENABLED mode=DAMP` |
| `#DIS` | **失能**（…FD）→ 停帧，⚠️**轴自由（无抱闸）** | `@OK DIS done` + `@EVT DISABLED` |
| `#STOP` | **软急停**：回阻尼（**保持使能**，防坠） | `@OK STOP mode=DAMP (still enabled)` + `@EVT STOP mode=DAMP` |
| `#ESTOP` | **硬急停**：停帧 + 失能（⚠️轴自由，会掉） | `@OK ESTOP mode=DISABLED (shaft FREE)` + `@EVT ESTOP mode=DISABLED` |
| `#ZERO CONFIRM` | 把当前位置写为**零点**（⚠️掉电持久） | 不带 CONFIRM 时先回：`@ERR 4 ZERO persistent! resend as '#ZERO CONFIRM' (writes motor zero, survives power-off)`；加了 CONFIRM → `@OK ZERO done` + `@EVT ZERO` |

**运动（都要先 `#EN`）**

| 发送 | 干什么 | 回包 |
|---|---|---|
| `#DAMP [kd]` | 回阻尼（可拖动、不发力）；可顺带改阻尼系数 | `@OK DAMP kd=1.00` |
| `#HOLD` | 同回阻尼（语义化别名） | `@OK HOLD mode=DAMP` |

## §3 按场景（可整块照抄）

### 3.1 刚上电，确认一切正常
```
#PING          → @OK PING ms=..
#VER           → 看 scale=output、pmax=720（双编口径）
#STAT          → mode=IDLE en=0 rx=0（未使能时 rx=0 正常：本电机"一发一收"）
```
屏 `LINK 1/4` 应显示 `READY`（有反馈）或 `INIT OK WAIT`（还没开始通信）。

### 3.2 使能 → 确认反馈流 → 台架试转（完整流程）
```
#LOG 1
#EN            → @OK EN mode=DAMP frames=ON / @EVT ENABLED mode=DAMP
#TEL 50        → 每秒 20 条 @TEL，age 应为个位 ms、rx 持续增长
（手拧输出轴：应有阻力、松手停住）
#WD 0          → 台架模式（不因心跳超时中断）
#LIM T 1       → 力矩安全网 1 N·m
#SET KP_V 0.002
#V 5           → 慢转
（观察：平稳、方向对、vel 贴近 5）
#V 0           → 停转（保持阻尼）
#STOP          → 回阻尼
#WD 200        → 恢复心跳保护
#DIS           → 失能（轴自由）
```

### 3.3 速度模式调参（抖 → 稳）
| 现象 | 处理 |
|---|---|
| 猛抖一下 | `#SET KP_V 0.001`，或 `#SET TRATE 5`（更慢的力矩斜率） |
| 转但跟不上/太慢 | `#SET KP_V 0.005` 再试；有摩擦可给前馈：`#V 5 1.0 0.05`（kd=1.0, tff=0.05 N·m） |
| 稳态有小偏差 | 加大 `#SET KI_V 0.001`（别超过 0.01） |
| 方向反 | 用负值（`#V -5`）验证；长期要改固件 `J8108_DIR` |

### 3.3b 速度模式：推荐起始参数（空载台架，可直接照抄）

**一句话**：从小力矩、慢斜率、小增益起步，平稳了再往上加。

```
#EN                 → @OK EN mode=DAMP frames=ON
#LOG 1              （保留事件日志，便于排查）
#WD 0               （台架模式：不因心跳超时中断）
#LIM T 2            （力矩安全网 2 N·m；先试手感可用 1）
#SET TRATE 5        （力矩斜率 5 N·m/s = 每 5ms 只涨 0.025 N·m —— 小惯量关节稳的关键）
#SET KP_V 0.003     （速度误差→力矩：误差 10°/s 时给 0.03 N·m）
#SET KI_V 0.0003    （慢慢补齐摩擦/静差）
#V 10               （目标 10°/s 慢转）
#TEL 100            （10Hz 遥测，观察 vel/T）
```

**⚠️ 若「发 `#V` 后轴先抖、过很久才慢慢转、转起来后又很平稳」** —— 这是**静摩擦(stiction) + 积分太慢**的典型三连，不是代码问题。判据（从 `@TEL`/日志读）：
- 卡着不动时 `T` 在涨（如 0.03→0.25 N·m）、`vel≈0` → 正在「攒力矩挣脱静摩擦」；
- 一旦超过静摩擦，动摩擦**小得多**（如 0.1 N·m）→ 同样力矩就绰绰有余 → 平稳转动；
- 期间 `vel` 有 ±50% 纹波 = 黏滑振荡（粘住→攒力→突然滑动超速→回粘）。

**修法三件套（立刻见效）**：
```
#SET KI_V 0.02      ← 积分快 60 倍（0.02×10dps = 0.2 N·m/s）→ 1~2 秒就能挣脱
#SET TRATE 20       ← 让力矩能快速爬到摩擦量级
#SET TFF 0.15       ← ★摩擦前馈：填「转起来后维持转动所需力矩」（从日志 T 列估）
#V 10               ← 之后普通 #V 即可，前馈自动按方向生效
```
> **⚠️ 固件版本差异**：`#SET TFF` 需要 **v0.1.60-dev 及以上**；在更早的固件上会回 `@ERR 2 SET unknown key`，此时用**等价写法**：`#V <dps> <kd> <tff>`（第 3 参就是一次性摩擦前馈），例如 `#V 10 0.3 0.15`。
> 前馈值怎么估：转起来后 1Hz 数据里 `T` 的中位数（如 0.04~0.15 → 先取 0.12~0.15）。
> **内环阻尼提示**：速度模式下 `KD_DAMP` 会作为电机内部阻尼（`T=−KD_DAMP×v`，10dps 时 kd=1.0 就有 ~0.17 N·m 阻力，与摩擦同量级）→ 速度模式建议 `#SET KD_DAMP 0.2~0.5`（阻尼保持模式才用 1.0）。
> 想更稳：微调 `#SET TFF` 到「起步不抖、稳态 vel 贴住目标」；仍抖就把 `KP_V` 降到 0.002。

**阶梯（每档跑 30 秒，看上表判据）**：
| 档 | `KP_V` | `TRATE` | `#V` | 期望 |
|---|---|---|---|---|
| 1 | 0.003 | 5 | 10 | 平稳慢转（保底档） |
| 2 | 0.005 | 10 | 20 | 响应更跟手 |
| 3 | 0.008 | 20 | 30 | 接近实用（空载极限附近） |

**判据（看 `@TEL` 与 `@EVT`）**：
- `age` 个位 ms（数据新鲜）；`vel` 稳定贴近目标（±10% 内）；`T` **不长期贴住** `#LIM T` 的值；
- `vel` 符号与目标一致（不一致就是方向问题，记下来）;
- `@EVT LIMIT what=trate` **偶尔一条正常**（力矩在按斜率爬升）；**刷屏**才异常。
- **抖动/嗡鸣** → 回上一档；或只降 `TRATE`（力矩爬得更缓）；
- **跟不上** → 先加 `TRATE`，再考虑 `KP_V`；
- **稳态总差一点** → `KI_V` 每次乘 2（0.0003→0.0006→0.0012），别超 0.01。

收尾：`#V 0` → `#STOP` → `#WD 200` →（要松开轴）`#DIS`。

### 3.4 位置模式（点对点）
```
#P 10          → @OK P target=10.00 deg mode=POS kp=20.0 kd=1.00
（稳定后屏 P1 出现 INPOS 1）
#P -10         → 反向
#P 9999        → @ERR 7 P outside soft limits (see #LIM)   ← 被软限位挡住
#LIM P -30 30  → 改软限位
#P 90          → 目标被夹到 30°，出现一次 @EVT LIMIT what=setpoint
```
- 起始点自动预置为**当前实际角**（不会从 0° 冲）。
- `#P <deg> <kp> <kd>` 可当场调位置增益（Kp≤500、Kd≤5，**两者都要给**，只给 Kp 会震）。

### 3.5 力矩 / 阻抗（⚠️需负载）
```
#T 0.3         → 0.3 N·m（空载会持续加速！务必立刻 #STOP）
#T 99          → @ERR 2 T exceeds #LIM T (torque clamp)
#IMP 10 0.5    → 阻抗：参考角=当前角，Kp=10 Kd=0.5；手推有"弹簧+阻尼"感
#IMP 10 0.5 0.2→ 额外加 0.2 N·m 前馈（托举重力用）
```

### 3.6 掉线 / 恢复
```

[J8108] W: link lost (no ACK) -> will retry ENABLE in 500ms (1/4)
```

### 3.8 这些参数到底在管什么（易混五件套）

**先分清"谁是增益、谁是限制、谁才是加速度"**：

| 参数 | 单位 | 管什么 | 直觉（打油门比方） |
|---|---|---|---|
| `KP_V` | N·m per (deg/s) | **速度误差 → 力矩** 的比例换算 | **踩油门的灵敏度**：速度差得多就踩得深 |
| `KI_V` | N·m per (deg/s·s) | 误差**随时间累计**再加力矩 | 慢慢补齐"总是差一点"的常态偏差（摩擦/重力） |
| `RATE` | **deg/s²** | **指令速度**的变化率上限（目标 0→5°/s 用多久） | 指令侧的加速度限制 |
| `TRATE` | N·m/s | **力矩**的变化率上限（力矩怎么爬到目标值） | 油门**踩下去的速度**；除以关节惯量≈"加速度爬升率" |
| `TMAX`（`#LIM T`） | N·m | 力矩上限 | 决定**真正的最大角加速度**：`角加速度 = 力矩 ÷ 惯量` |

**速度环每 5ms 实际算的**：
```
力矩 = KP_V × (目标速度 − 实测速度) + 积分项 + 前馈项
     → 限幅到 ±TMAX → 再按 TRATE 限制"每周期最多涨多少"
```
所以 **`KP_V` 是"误差→力矩"的换算系数，不是加速度**：它决定"跟得紧不紧"，不决定"能跑多猛"（那是 `TMAX` 与惯量的事）。

**代入你的数值**（`#SET KP_V 0.002`）：
```
目标 5°/s、当前 0 → 误差 5 → 力矩 = 0.002 × 5 = 0.01 N·m   （很温柔）
        当前 3 → 误差 2 → 力矩 = 0.002 × 2 = 0.004 N·m  （快到了就松）
对照旧默认 0.05：误差 5 → 0.25 N·m → 小惯量关节一周期就冲过头 → 猛抖
```

**调参手感（速度模式）**：
| 现象 | 动哪个 |
|---|---|
| 跟不上目标 | `KP_V` 加大（0.002 → 0.005 → 0.01，别超 0.01） |
| 抖动/嗡鸣 | `KP_V` 减小，或 `TRATE` 减小（力矩爬得更慢） |
| 稳住了总差一点 | `KI_V` 慢慢加（0.0002 → 0.001）；有摩擦/重力再加前馈 `#V <dps> <kd> <tff>` |
| 起步"顿一下" | `TRATE` 与 `RATE` 都减小（力矩/目标都更缓） |

### 3.9 参数不全时，板子会告诉你用法（逐字）

```
@ERR 2 V usage: #V <deg/s> [kd] [tff]
@ERR 2 P usage: #P <deg> [kp] [kd]
@ERR 2 T usage: #T <Nm>
@ERR 2 IMP usage: #IMP <kp> <kd> [tff]
@ERR 2 LIM usage: #LIM [P min max | V max | T max]
@ERR 2 LOG usage: #LOG <0=err|1=info|2|3=debug>
@ERR 2 MODE usage: #MODE <IDLE|DAMP|SPEED|POS|TORQUE|IMP>
@ERR 2 RATE usage: #RATE <deg/s^2>
@ERR 2 WD usage: #WD <ms>  (0=off)
@ERR 2 TEL usage: #TEL <0=off | 1=once | period_ms 2..1000>
@ERR 2 SET usage: #SET <key> <value>  (see #GET)
@ERR 2 SETP usage: #SETP <p_rad> <v_rps> <kp> <kd> <t_nm>
```

## §4 回包格式（怎么读）

| 前缀 | 含义 | 例子 |
|---|---|---|
| `@OK <命令> k=v ...` | 命令**已接受/已执行** | `@OK V target=5.00 dps mode=SPEED` |
| `@ERR <码> <命令> <原因>` | 命令**被拒**（原因在最后） | `@ERR 3 V not enabled (send #EN first)` |
| `@EVT <事件> k=v` | **异步事件**（与命令无一一对应） | `@EVT TIMEOUT mode=DAMP` |
| `@TEL ...` | 周期遥测 | `@TEL ms=.. mode=SPEED en=1 pos=.. vel=.. T=.. Tm=.. Tr=.. err=0x00 set=.. age=5` |
| `[tag] I:/W:/E: ...` | 板子日志（**不是回包**），发 `#LOG 0` 可压掉 | `[J8108] W: EVT TIMEOUT: ...` |

**`@STAT`/`@TEL` 字段**：`mode` 模式 · `en` 是否使能 · `pos` 输出端角度(deg) · `vel` 输出端速度(deg/s) · `T` 实际力矩(N·m) · `Tm/Tr` MOS/线圈温度(℃) · `err` 电机报错位(0x00 正常) · `rx/tx` 收发帧数 · **`age` 距最近一帧反馈的毫秒数（>200 就是链路断了）** · `hold` 正在发控制帧 · `set` 当前设定点。
**`link=DOWN`**：数据不新鲜时 `@TEL` 会只报 `link=DOWN age=..`，**不打旧数值**（有意为之）。

## §5 错误码与事件

| 码 | 含义 | 常见触发 |
|---|---|---|
| `1` | 未知命令 | 拼错命令（`#FOO`） |
| `2` | 参数错/越界/格式错 | `#V 1.2.3`、`#LIM P 90 -90`、`#T 99` |
| `3` | 未使能 | 没 `#EN` 就发 `#V/#P/#T/#IMP` |
| `4` | 模式不允许 / 已锁定 | `#ZERO` 无 CONFIRM、`#SETP` 未解锁 |
| `5` | 电机报错 或 帧未收到 ACK | 24V/CAN_H-L/120R/CANID 有问题 |
| `6` | **自检失败**（`#ST` 里出现了 `3`） | 模块初始化失败/任务没起来（看开机日志与 `@BOOT` 横幅） |
| `7` | 软限位 | `#P 9999`（先 `#LIM P`） |
| `8` | 内部忙/超时 | 控制任务繁忙（偶发） |
| `9` | **该模块本固件未编译** | `#ST disp` 但当前 profile 不含显示模块 |

**`#ST` 自检码**：`0`=本固件未编译该模块（对照 `@BOOT` 横幅） · `1`=OK · `2`=WARN（活着但状态可疑：CAN 总线错误 / 屏 2s 没刷新 / 按键一直按住 / 监视循环 500ms 没动静） · `3`=FAIL（初始化失败或任务没起来）。**全部非破坏性**：只读状态，不发帧、不写外设。

**事件 `@EVT`**：`ENABLED` / `DISABLED` / `ZERO` / `CLRERR` / `MODE=<M>` / `TIMEOUT`(心跳超时→阻尼) / `STOP` / `ESTOP` / `LIMIT what=setpoint|torque` / `FOLLOW`(跟随误差超限→阻尼) / `STALL`(堵转→阻尼) / `TEMP Tm=.. Tr=..` / `ERR=0xNN what=...`(电机报错位) / `LINKLOST what=noack|nofb`。

**`@EVT LIMIT what=?` 的三个来源（v0.1.55 起细分）**：
| `what=` | 意思 | 通俗解释 | 要处理吗 |
|---|---|---|---|
| `setpoint` | 设定点被软限位/限速夹紧 | 你让转 90°，但 `#LIM P` 只允许到 30° | 正常（改 `#LIM` 或目标） |
| `torque` | 力矩撞到 `TMAX`（`#LIM T`）上限 | 想要的力矩超过上限，被切平 | 长期如此：加大 `#LIM T` 或减小 `KP_V` |
| `trate` | 力矩被**斜率限制**（`TRATE`）限速 | 「油门踩下去的速度」被限住（正在 ramp） | **正常现象**，不用管；嫌响应慢就加大 `#TRATE` |

**同一条件只报一次**（需连续 1s 恢复正常才允许再报）→ 不会再刷屏（v0.1.55-dev 起）。

## §6 危险命令（用前必须知道）
| 命令 | 风险 | 前提 |
|---|---|---|
| `#DIS` / `#ESTOP` | **本电机无抱闸 → 轴自由，关节会掉** | 托住负载或用 `#STOP`（阻尼）代替 |
| `#T <Nm>` | 空载持续加速、撞限位 | 必须有负载或人扶；小值起步（0.3） |
| `#ZERO CONFIRM` | **改机械零点且掉电保存** | 先记下 `#STAT` 的 pos；确认零点语义 |
| `#SET SETP 1` + `#SETP` | 绕过所有限幅，直发电机原始单位 | 仅在诊断时、且知道量程 |
| `#WD 0` | 上位机失联后电机**继续执行**最后目标 | 只用于台架，用完恢复 `#WD 200` |
| `#SET TRATE 0` | 力矩不再限斜率 → 易触发抖动 | 基本不要用 |
| `#SET KP_V 0.05` 以上 | 极限环震荡（"猛抖"） | 小惯量关节别超 0.01 |

## §7 常见问题

### 7.1 发命令**完全没回包**
按屏 **P2 `SERIAL 3/4` 页**行2 `RX nL mB TX kL` 三步定位：
| 现象 | 原因 | 处理 |
|---|---|---|
| `RX 0L 0B` | 字节没进来 | 查端口选对没、TX/RX 是否接反、波特率、是否别处占用串口 |
| `RX 0L` 但 `B` 在涨 | 收到了字节但**没形成一行** | 终端勾"发送新行"；`\r`/`\n` 现在都接受 |
| `RX nL` 在涨但无回包 | 解析层 | 看日志前 3 条 `[cmd] I: rx line N: "..."`（原样回显你发的内容）并把它发我 |

### 7.2 `#V 20` 只转一下/抖一下就不动了
1. **心跳超时**（最常见）：`wd=200ms` 内没有新命令 → 自动退阻尼（`@EVT TIMEOUT`）。台架先 `#WD 0`；真实运行由上位机每 ≤100ms 发一次命令。
2. **增益过大**：抖动=极限环。`#SET KP_V 0.001`、`#SET TRATE 5`，并用 `#LIM T 1` 兜底。
   （若调大 `KP_V` 后看到 `@EVT LIMIT what=trate`，那是「力矩在按斜率爬升」，属于**正常**；v0.1.55 起同一条件最多 1 条，不再刷屏。）
3. **力矩被限死**：`#LIM T` 太小（如 0.1）→ 转不动但会出 `@EVT LIMIT what=torque`。

### 7.5 板子突然"没动静"了（回包被切断 / 完全无响应）
**先按下面三步取证（v0.1.57 起板子自带黑匣子）**：
1. **按复位键**（⚠️**不要断电**——崩溃现场存在 RTC 备份寄存器里，掉电会清）。
2. 看开机的 `[fault]` 行：
   - `black box: clean` → 上次没崩（那更可能是串口链路/上位机的问题，见 §7.1）
   - `PREVIOUS RUN CRASHED: HardFault ... PC=0x... LR=0x... CFSR=0x...` → **崩在 PC 那个地址**（把整行发我）
   - `PREVIOUS RUN CRASHED: STACK OVERFLOW in task 'xxx'` → 那个任务栈不够（发我）
3. 若已经断过电：用 Keil 挂上、**不要复位**，Stop 后在 Watch 窗口看 `s_hf_pc` / `s_overflow_task` 两个变量，同样能把死因读出来。
> 顺带确认：卡死时**屏幕还在刷新/按键还能翻页吗**？——还在刷 → 多半只是串口链路（USB-TTL/上位机）问题；屏幕也冻住 → 板子确实崩了。

### 7.3 `#EN` 回 `@ERR 5 EN no ACK on bus`
链路问题（**先查硬件，不要先怀疑代码**）：24V 是否上电 · CAN_H/CAN_L 是否接反 · 电机端 120Ω 开关是否拨到开 · A 板 CAN1 H–L 与电机是否**共地** · 电机 CANID 是否 0x01（别的就用 `#VER` 看当前值）。

### 7.4 屏上 `pos` 与实际角度差 8 倍
口径问题：本机按**双编版**（输出端，`PMECH=±12.56rad=±720°`）实现；若实测差 8 倍说明电机固件是单编版 → 需改固件 `J8108_SCALE_OUTPUT_SIDE 0` 重编（见测试手册 L6 实验 EXP-01）。

## §8 按键与屏幕（不用串口也能操作/查看）
| 操作 | 效果 |
|---|---|
| 单击 | 下一页（`LINK→MOTION→SERIAL→SYSTEM→LINK`） |
| 双击 | 上一页 |
| 长按 ≥2s | 回第 1 页 |
| ⚠️ 按键**不控制电机**（只翻页；这是本次改版的硬约定） |

## §9 上位机（Python）发送示例

```python
import serial, time
ser = serial.Serial("COM3", 115200, timeout=0.05)

def send(cmd):
    ser.write((cmd + "\n").encode())          # 换行必须
    time.sleep(0.15)                          # 等回包
    for l in ser.read(ser.in_waiting).decode(errors="replace").splitlines():
        if l.startswith("@"):
            print(l)

send("#EN")
send("#WD 0")
send("#V 5")
time.sleep(3)                                  # 台架：WD=0 才不会掉
send("#STOP")
ser.close()
```
