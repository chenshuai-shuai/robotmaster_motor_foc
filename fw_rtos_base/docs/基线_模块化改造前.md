## 5. 屏上逐字内容（4 页，改造回归的比对基准）

> 抽取自 `Task/Src/Oled_Task.c`（改造前）。M1–M3 之后这 4 页必须**逐字一致**。

**P0 LINK**

| 行 | 格式串 |
|---|---|
| 0 | `LINK %u/%u %s`（状态四态：INIT FAIL / INIT OK WAIT / READY / BUS ERR） |
| 1 | `RX %lu TX %lu` |
| 2 | `ERR OK (%s)` 或 `ERR 0x%02X %s` |
| 3 | `TEC%3lu REC%3lu LEC%lu` 或 `BUS OK (HAL 0x%04lX)` |
| 4 | `AGE never  LINK DOWN` / `AGE %lums  %uHz` / `AGE %lums  LINK DOWN` |
| 5 | `MODE %s EN %u` |
| 6 | `SET %8.2f %s` |
| 7 | `KEY CLK=next DBL=prev` |

**P1 MOTION**

| 行 | 格式串 |
|---|---|
| 0 | `MOTION %u/%u %s` |
| 1-3 | `POS %9.2f deg` / `VEL %9.2f dps` / `T   %9.3f Nm`（不新鲜时：`POS      ---- deg` 等） |
| 4 | `SET %9.2f deg` / `SET %9.2f dps` / `SET %9.3f Nm` / `SET      ---- ` |
| 5 | `KP %5.1f KD %5.2f` |
| 6 | `Tm %4.1fC Tr %4.1fC`（不新鲜：`Tm   --.-C Tr  --.-C`） |
| 7 | `EN %u SEND %u INPOS %u` |

**P2 SERIAL**

| 行 | 格式串 |
|---|---|
| 0 | `SERIAL %u/%u` |
| 1 | `LAST #%s` |
| 2 | `RX %luL %luB TX %luL` |
| 3 | `WD LEFT %5ums` |
| 4 | `MOTOR ERR 0x%02X` |
| 5 | `PROTO ERR 0 (none)` / `PROTO ERR %u` |
| 6 | `TEL off` / `TEL %ums` |
| 7 | `#EN #V #P #STOP` |

**P3 SYSTEM**

| 行 | 格式串 |
|---|---|
