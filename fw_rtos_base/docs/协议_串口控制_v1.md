## 1. 目标与架构

```
上位机(PC · python/串口助手)
   │  ASCII 行协议 115200 8N1
   ▼
A 板 F427 ── 外环控制器（位置 PD / 速度 PI+前馈 / 阻尼 / 力矩 / 阻抗）@200Hz~1kHz
   │  CAN 1Mbps 经典帧，8 字节大端
   ▼
8108 驱动板 ── 内环（电流/力矩），MIT 帧 = 力矩接口
```

**核心设计原则**

1. **控制环跑在 A 板内部**（200Hz~1kHz），串口只承载"命令 + 低频遥测"，不参与闭环 → 上位机卡顿/断连不会让电机失控。
2. **只用电机的 MIT 模式**（`ControlMode:0`），位置/速度/力矩/阻尼**全部由 A 板合成**；双编固件的原生 `位置速度/速度模式`（0x301/0x101）留作二期性能选项（需额外接一路 UART 到电机配置口）。
3. **协议与日志物理同口、逻辑隔离**：命令以 `#` 开头、回包/事件/遥测以 `@` 开头、日志保持 `[tag]` 前缀 → 上位机只解析 `@` 行；`#LOG 0` 可静音日志。
4. **失效安全**：任何异常（心跳超时、参数越界、状态不符）都退到**阻尼保持**（不是失能）——本电机无抱闸，失能会自由坠落。

## 2. 物理层与帧格式

### 2.1 物理层

| 项 | 值 |
|---|---|
| 端口 | **USART6**（A 板丝印「UART」4 针口），TX=**PG14** / RX=**PG9** |
| 参数 | **115200 8N1，3.3V TTL**（二期可升 921600，见 §11） |
| 接线 | 3 线：板 T→USB-TTL RX、板 R→USB-TTL TX、G↔G |
| 共用 | 与日志同口；协议行与日志行靠前缀区分 |

### 2.2 行格式

```
上位机 → A 板 :   #<CMD> [arg1] [arg2] ... \r\n      （\n 单独结尾亦接受）
A 板 → 上位机 :   @OK  <CMD> [k=v ...]               成功
                  @ERR <code> <CMD> <原因>            失败
                  @EVT <NAME> [k=v ...]              异步事件（保护/状态变化）
                  @TEL <k=v ...>                     周期遥测（#TEL 使能后）
                  [tag] I/W/E: ...                   日志（可被 #LOG 静音）
```

| 规则 | 说明 |
|---|---|
| 大小写 | 命令名与参数关键字**不区分大小写** |
| 数值 | 十进制，可带小数与负号（`-12.5`）；十六进制仅 `#RAW/ #SETP` 等调试命令使用 |
| 编码 | **纯 ASCII**（兼容中文注释仅在日志中禁止） |
| 行长 | 单行命令最长 **128 字节**，超长丢弃并回 `@ERR 2` |
| 应答 | **每条命令必有一条 `@OK`/`@ERR`**（上位机可做超时与同步） |
| 回包顺序 | 先执行动作再回包；异步事件可能紧跟其后 |

## 3. 单位与坐标系常量

### 3.1 单位约定（关节端 / 输出端）

| 物理量 | 单位 | 说明 |
|---|---|---|
| 位置 `pos` / `p_des` | **deg** | 输出轴角度，范围由 §3.2 实测确定（当前软限位 ±170°） |
| 速度 `vel` / `v_des` | **deg/s** | 输出轴角速度 |
| 力矩 `T` / `t_ff` | **N·m** | 输出轴力矩（额定 7.5 / 堵转 22，命令限幅默认 7.5） |
| 温度 | ℃ | `Tm`=MOS、`Tr`=线圈 |
| 增益 `Kp`/`Kd` | 无量纲 | 沿用电机口径：Kp 0~500、**Kd 0~5** |
| 原始帧字段 | rad / rad/s / N·m | 仅 `#SETP` / `#RAW` 使用（电机口径，不做换算） |

### 3.2 口径常量（**双编文档口径为准**；实验 A/B 只做核对与定号）

| 常量 | 含义 | 取值（来源） |
|---|---|---|
| `SCALE_MODE` | 位置/速度端别 | **`output_side`** —— 双编文档 §3.1 明确"POS = 电机**输出端**位置(rad)"、"VEL = 输出端速度(rad/s)"，**不做 ÷8** |
| `PMECH` | 位置量程 | **±12.56 rad（±720°）** —— 双编文档 §3.1/§3.2.2/§4.2 的 `PMAX` 默认值。**建议用配置串口把它收成本关节实际机械范围**（例：`PMAX:3.14` ⇒ ±180°），既提分辨率又提安全性 |
| `VEL_SIDE` | 速度端别 | **`output`**（同 `SCALE_MODE`） |
| `VMAX` / `TMAX` | 速度/力矩量程 | **±45 rad/s** / **±18 N·m**（双编文档默认；可用 `VMAX:`/`TMAX:` 收窄） |
| `DIR` | 正方向符号 | **待实验 B3**（+1 或 −1） |
| `GEAR` | 减速比 | 8（仅当 `SCALE_MODE=motor_side` 时才用于换算） |
| `MOTOR_ID` | 电机 CANID | 0x01 |

**换算（A 板内部唯一换算点，集中在 `motor_8108.c`）**

```
双编口径（默认生效）：
  输出端 → 帧值： p_conv = DIR × p_deg × π/180          （不再 ×GEAR）
                  v_conv = DIR × v_dps × π/180
                  t_conv = T_nm
  帧值 → 输出端： 反向同理（反馈解算不再 ÷8）

【兜底】若实验 A 判定为单编固件（Encoder:1）：
  p_conv = DIR × p_deg × π/180 × GEAR ；解算时 ÷GEAR ；PMECH = ±25.12 rad（电机端）
```

> `#VER` 回包必须报告 `scale`、`pmax`、`vmax`、`tmax`、`gear`、`dir` → 上位机/人**一眼可核对**口径是否配对，避免 8 倍错误。

## 4. 控制模式状态机（A 板外环）

| 模式 | 语义 | 每帧 MIT 参数（200Hz~1kHz） |
|---|---|---|
| `IDLE` | 上电默认：只监听，**不发任何帧** | — |
| `DAMP` | **阻尼保持**（安全态）：`T = −Kd·v` | Kp=0, Kd=`kd_damp`, v_des=0, t_ff=0 |
| `SPEED` | **指定速度旋转**（外环 PI + 摩擦前馈） | Kp=0, Kd=`kd_damp`, v_des=0, t_ff=`PI(v_err)+T_fric` |
| `POS` | **绝对位置**（先纯 PD，用电机内环 PD） | Kp=`kp_pos`, Kd=`kd_pos`, p_des=目标, v_des=0 |
| `TORQUE` | 力矩（限幅） | Kp=0, Kd=0, t_ff=T |
| `IMP` | 阻抗/柔顺（进入时锁当前角） | Kp=`kp_imp`, Kd=`kd_imp`, p_des=进入时角度, t_ff |
| `MOVE` | 点到点轨迹（**二期**：梯形/S 曲线） | 流式 p_des/v_des |

**规则**

1. **任何模式切换先经 `DAMP`**（安全过渡，停一帧再进目标模式）。
2. 切模式**不改变使能状态**；失能状态下运动命令一律 `@ERR 3`。
3. 位置/速度/力矩设定点均经**速率限制 + 限幅**后才进帧（§8）。
4. 位置模式到位后持续 PD 顶住，并在首次进入到位带时发一次 `@EVT INPOS`。

**默认参数（`#SET` 可改；二期 `#SAVE` 存 Flash）**

| 参数 | 默认 | 说明 |
|---|---|---|
| `kd_damp` | 1.0 | 阻尼系数（0~5，过大震荡） |
| `kp_pos` | 20.0 | 位置增益（0~500；**必须配 kd_pos**，文档明确 Kp≠0&Kd=0 会震荡失控） |
| `kd_pos` | 1.0 | 位置模式阻尼 |
| `kp_v` | 0.05 | 速度环比例（N·m per deg/s） |
| `ki_v` | 0.002 | 速度环积分 |
| `kp_imp` / `kd_imp` | 10.0 / 0.5 | 阻抗模式默认刚度/阻尼 |
| `inpos_deg` | 1.0 | 到位判定带（±1°） |
| `boot_enable` | **0** | 上电是否自动使能（默认 0 = 需显式 `#EN`，安全优先） |
| `autodamp_on_err` | 1 | 电机 ERR 位非 0 时自动进 DAMP |

## 5. 命令总表（一期）

> 语法中 `[]` = 可选参数；范围外的参数 → `@ERR 2`。

### 5.1 系统类

| 命令 | 语法 | 回包 | 行为 |
|---|---|---|---|
| PING | `#PING` | `@OK PING ms=<t>` | 存活 + A 板时基（最轻量，可当心跳） |
| 版本 | `#VER` | `@OK VER fw=<ver> proto=1 units=deg,dps,Nm pmax=<> vmax=45 tmax=18 scale=<> gear=8 dir=<> canid=1 ctrl=200Hz` | 报告口径常量，供上位机自检 |
| 状态 | `#STAT` | `@OK STAT mode=<M> en=<0/1> pos=<> vel=<> T=<> Tm=<> Tr=<> err=0xNN rx=<> tx=<> age=<>ms hold=<0/1> set=<>` | 一行状态快照 |
| 日志 | `#LOG <0..3>` | `@OK LOG lvl=<n>` | 0=只错误 1=事件(默认) 2=详细 3=调试 |
| 清错 | `#CLR` | `@OK CLR err=0xNN` | 发 `ID 0x001 …FA` 清电机 ERR 位 + 清本地统计 |
| 设参 | `#SET <k> <v>` | `@OK SET <k>=<v>` | 改 §4 默认参数（重启失效，二期持久化） |
| 读参 | `#GET` | `@OK GET kd_damp=1.0 kp_pos=20 ...` | 列出当前参数 |

### 5.2 使能与安全类

| 命令 | 语法 | 回包 | 行为 |
|---|---|---|---|
| 使能 | `#EN` | `@OK EN mode=DAMP` | 发 `…FC` → 20ms 内被 ACK 才成功（否则 `@ERR 5`）→ 自动进 `DAMP` 并开始发帧 |
| 失能 | `#DIS` | `@OK DIS` | 先退出模式停发 → 发 `…FD`；`@EVT DISABLED` |
| 急停(软) | `#STOP` | `@OK STOP` + `@EVT STOP` | 立即进 `DAMP`、清设定点、**保持使能**（防坠） |
| 急停(硬) | `#ESTOP` | `@OK ESTOP` + `@EVT ESTOP` | 停发 + `…FD` 失能（**输出轴自由，注意负载**） |
| 零点 | `#ZERO`（二期，需 `#ZERO CONFIRM`） | `@OK ZERO` | 发 `…FE` 设当前位置为零点（掉电保存） |

### 5.3 运动类

| 命令 | 语法 | 范围 | 行为 → MIT 参数 |
|---|---|---|---|
| 模式 | `#MODE <IDLE\|DAMP\|SPEED\|POS\|TORQUE\|IMP>` | — | 先经 DAMP 再进目标模式；`@EVT MODE=<M>` |
| 阻尼 | `#DAMP [kd]` | kd 0~5 | Kp=0, Kd=kd, v_des=0, t_ff=0 |
| 速度 | `#V <dps> [kd] [tff]` | \|dps\|≤vmax | Kp=0, Kd=kd, v_des=0, t_ff=PI(v_err)+T_fric+tff（持续型） |
| 位置 | `#P <deg> [kp] [kd]` | 软限位内 | Kp=kp, Kd=kd, p_des=目标, v_des=0（到位保持，发 `@EVT INPOS`） |
| 力矩 | `#T <Nm>` | \|T\|≤tmax | Kp=0, Kd=0, t_ff=T（**空载大扭矩会持续加速**——文档已警告，务必配限速） |
| 阻抗 | `#IMP <kp> <kd> [tff]` | kp 0~500, kd 0~5 | Kp=kp, Kd=kd, p_des=进入时角度, t_ff=tff |
| 保持 | `#HOLD` | — | 等价 `#MODE DAMP`（回到安全态） |
| 调试直通 | `#SETP <p_rad> <v_rps> <kp> <kd> <t_nm>` | 电机口径 | 原样透传（**不做单位换算/不夹紧**，仅标定用；需 `#SET safety 0` 解锁） |

### 5.4 限制与安全类

| 命令 | 语法 | 回包 | 说明 |
|---|---|---|---|
| 查询限幅 | `#LIM` | `@OK LIM pmin=-170 pmax=170 vmax=300 tmax=7.5 rate=3000 wd=200` | — |
| 位置限位 | `#LIM P <min> <max>` | `@OK LIM P min=<> max=<>` | A 板侧夹紧（二期可同步写电机 `PMAX`） |
| 速度限幅 | `#LIM V <max>` | `@OK LIM V max=<>` | — |
| 力矩限幅 | `#LIM T <max>` | `@OK LIM T max=<>` | — |
| 速率限制 | `#RATE <deg/s²>` | `@OK RATE <v>` | 位置/速度设定点变化率（防抖动冲击） |
| 心跳超时 | `#WD <ms>` | `@OK WD <ms>` | 0=关闭；超时 → `DAMP` + `@EVT TIMEOUT` |

### 5.5 遥测类

| 命令 | 语法 | 回包 | 说明 |
|---|---|---|---|
| 周期遥测 | `#TEL <ms>` | `@OK TEL period=<ms>` | **默认建议 20Hz（50ms）**；0=关 ⚠️ **实现现状：默认关（`MON_DEF_TEL_MS=0`），需 `#TEL 50` 显式打开** |
| 单次遥测 | `#TEL 1` | `@TEL ...` | 立即一条 |

**遥测行格式**（`k=v`，字段定序）

```
@TEL ms=123456 mode=POS en=1 pos=12.34 vel=0.50 T=0.120 Tm=40.4 Tr=29.4 err=0x00 set=12.00 age=5
```

| 字段 | 含义 |
|---|---|
| `ms` | A 板时基（ms，回绕） |
| `mode` / `en` | 当前模式 / 是否使能 |
| `pos` `vel` `T` | 输出端位置(deg) / 速度(deg/s) / 力矩(N·m) |
| `Tm` `Tr` | MOS / 线圈温度（℃） |
| `err` | 电机 ERR 报错位（§7.2） |
| `set` | 当前设定点（位置模式=目标角，速度模式=目标速度） |
| `age` | 距上一条**新**反馈帧的时延（ms）→ 上位机判链路是否新鲜 |

## 6. 事件（`@EVT`）

| 事件 | 触发 | 示例 |
|---|---|---|
| `ENABLED` / `DISABLED` | 使能状态变化 | `@EVT ENABLED mode=DAMP` |
| `MODE=<M>` | 模式切换完成 | `@EVT MODE=POS` |
| `INPOS` | 位置模式进入 ±`inpos_deg` 带 | `@EVT INPOS pos=12.03` |
| `TIMEOUT` | 心跳超时（已退阻尼） | `@EVT TIMEOUT wd=200` |
| `LIMIT` | 设定点被限位/限幅夹紧 | `@EVT LIMIT what=P val=200 clamped=170` |
| `STOP` / `ESTOP` | 急停 | `@EVT ESTOP` |
| `ERR=0xNN` | 电机 ERR 位非 0（附解码） | `@EVT ERR=0x40 faults=OVERTEMP_MOTOR` |
| `TEMP` / `STALL` / `FOLLOW` | 温度预警 / 堵转 / 跟随误差超限 | `@EVT STALL T=8.3 v=3` |

## 7. 错误与报错位

### 7.1 协议错误码（`@ERR <code>`）

| 码 | 含义 |
|---|---|
| 1 | 未知命令 |
| 2 | 参数越界 / 格式错误 / 行长超限 |
| 3 | 未使能（需先 `#EN`） |
| 4 | 当前模式不允许该操作 |
| 5 | 电机报错或帧未被 ACK（CAN 无应答） |
| 6 | 心跳超时（提示） |
| 7 | 软限位（设定点被拒） |
| 8 | 内部忙 / 正在切模式 |

### 7.2 电机 ERR 报错位（反馈帧 Byte0，双编文档 §3.1）

| Bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|---|---|---|---|
| 含义 | 过载 | 线圈过温 | MOS 过温 | 过流 | 过压 | 欠压 | 保留 | 保留 |

> 实测常态读 `0x00`（无错）。置位 → `@EVT ERR=0xNN`；`autodamp_on_err=1` 时自动进 `DAMP`。清错用 `#CLR`（`…FA`）。

## 8. 安全策略（默认值，全部 A 板侧强制）

| 机制 | 默认 | 动作 |
|---|---|---|
| 心跳看门狗 | **200 ms** 无命令 | 进 `DAMP` + `@EVT TIMEOUT` |
| 软限位 | ±170° | 设定点夹紧 + `@EVT LIMIT` |
| 设定点速率限制 | 3000 deg/s² | 斜坡限制 |
| 速度上限 | 300 deg/s | 夹紧 |
| 力矩上限 | 7.5 N·m（额定；可放开至 15） | 夹紧 |
| 跟随误差 | >30° 持续 500ms | `@EVT FOLLOW` + `DAMP` |
| 堵转 | \|T\|>8 N·m 且 \|v\|<10 deg/s 持续 1s | `@EVT STALL` + `DAMP` |
| 过温 | Tm>70℃ 预警 / >85℃ | `@EVT TEMP` / `DAMP` 停机 |
| 电机 ERR 位 | 任一置位 | `@EVT ERR` +（默认）自动 `DAMP` |
| 物理急停 | 板载 **PB2 长按 2s**（现有功能，保持不变） | 失效安全的本地急停 |
| 上电默认 | 失能 + `IDLE`（`boot_enable=0`） | 需显式 `#EN` |

## 9. 上电与失联行为

| 场景 | 行为 |
|---|---|
| A 板上电 | 电机失能（硬件本性）→ A 板 `IDLE`，只监听不发帧；`boot_enable=1` 时才自动 `…FC` + `DAMP` |
| 上位机断连/静默 | 200ms 后进 `DAMP`（**保持使能、软住不掉**），持续保持直至 `#EN`/`#DIS` |
| A 板复位 | 电机状态不变（可能是使能+R/C）；A 板回 `IDLE`，需重新 `#EN` 建立控制流 |
| 电机掉线（无 ACK/无反馈） | 看门狗（连续 100ms 无 ACK）停发 + `@EVT`；反馈丢失 500ms 退 `IDLE`；退避自动重连（上限 4 次） |
| 串口噪声/非法命令 | `@ERR 1/2`，不影响当前控制流 |

## 10. 与现有固件的接口与任务划分

### 10.1 任务与优先级（定稿，2026-09-17）

| 任务 | 优先级 | 周期 | 职责 |
|---|---|---|---|
| `J8108_Task` | **5（最高）** | 1ms 轮询 / 200Hz 发帧 | 控制帧发生器、看门狗、退避自动恢复 |
| `KeyTask` | 4 | 10ms | 按键扫描 → 事件标志组（**只产事件，不发任何电机帧**）|
| `CmdRx` | 4 | 事件驱动 | 串口协议解析 / 分派 / 回包 |
| `Monitor_Task` | **3（低）** | 100ms 屏刷 / 1000ms 日志 / 20Hz 遥测 | 读帧一致快照 → 刷屏 + 打日志 + 发遥测 |
| `Led_Task` | **5**（实现值，见 `Led_Task.c:143`；早期设计写 2） | 512 | 心跳指示灯（纯 `vTaskDelay`，不抢 CPU） |

**三条硬约定**：① 屏刷/日志/遥测**永不在控制任务路径上**（软 I2C 阻塞 ms 级会毁掉 200Hz 发帧节拍）；
② 三层出口**同源快照**（不会出现屏/日志/遥测数据不一致，也不撕数据）；③ 屏/日志/遥测**都带 `age` 新鲜度**，
`age>200ms` 显示 `LINK DOWN`、**不打数值**。

**频率分层**：控制帧 200Hz（可配 1kHz，= 电机回传的驱动源）→ 屏刷 10Hz → 日志 1Hz → 遥测 ≤20Hz（115200 带宽 ≈100 行/s 上限）。
**CPU/带宽预算**：屏刷局部刷新 1~2 行 ≈1.3~2.6ms × 10Hz ≈ **2.6% CPU**；日志 1Hz ≈8ms 串口时间；遥测 20Hz ≈2KB/s ≈ **17% 带宽**。

## 12. 与现有实现的差异（唯一已知偏差，待修）

现有固件（v0.1.51-dev）的反馈解算按**单编**口径实现：`POS 原始码 → ±25.12 rad 电机端 → ÷8 得输出端`。
按双编口径应为：`原始码 → ±12.56 rad **输出端**直接取值`（不除 8）。两者对同一码值相差 **8 倍**。

| 影响面 | 现状 | 按双编应改为 |
|---|---|---|
| 屏上/日志角度 | `deg = pos/8 × 57.2958` | `deg = pos × 57.2958`（`±12.56 rad` 映射） |
| 屏上速度 | `RPM = vel × 9.5493`（暗示电机端） | 输出端 deg/s 直接换算 |
| MIT 帧 `p_des` 编码 | 按 ±25.12 电机端口径 | 按 ±12.56 输出端口径 |
| 位置软限位 | 隐含 ±180° | ±`PMECH`（默认 ±720°，建议按机械实际收窄） |

> 实施方式：把这些**集中成一张常量表**（`scale` 结构：`SCALE_MODE / PMECH / VEL_SIDE / DIR / GEAR`），
> 一处切换，屏/日志/协议/外环全部跟着走；`#VER` 回包报告当前口径供核验。
> 优先在实验 A/B 确认后**一次性改到位**（属代码改动，待协议批准后随实现一起做）。

## 13. 本地按键与屏幕的职责（2026-09-17 定稿）

> **决定**：控制命令全部走串口后，**板载按键（PB2）不再触碰电机**——只做 UI 导航；屏幕专职显示。

| 手势 | 动作 | 副作用 |
|---|---|---|
| 单击 | **下一页**（P0→P1→P2→P3→P0 循环） | 无 |
| 双击 | **上一页** | 无 |
| 长按 ≥2s 松手 | **回到 P0**（或按 §15 待定项再议） | 无 |
| 卡死（≥10s） | 该次手势作废 | 无 |

**屏幕页面（4 页）**

| 页 | 名称 | 内容 |
|---|---|---|
| P0 | `LINK` | CAN 四态 + `rx/tx` + 实测回传 Hz + **ERR 报错位**（置位反色）+ 页码 `1/4` |
| P1 | `MOTION` | 模式（IDLE/DAMP/SPEED/POS/TORQUE/IMP）+ 使能 + `pos/vel/T` + 设定点 + 双温度 |
| P2 | `SERIAL` | 协议态：最近命令、`RX/TX` 行数、**心跳剩余 ms**、最近 `@ERR`、遥测周期 |
| P3 | `SYSTEM` | 固件版本 + 运行时间 + free heap + 任务数 + 最近事件（保护触发）|

**安全含义（必须知晓）**：按键不再提供本地急停，本地兜底变为
① A 板心跳看门狗 200ms → 自动退阻尼（板子仍发帧，电机受控）② 拔电机 24V ③ A 板复位。
**本地急停的通知链**：若将来恢复本地停止按钮，须发 `@EVT LOCAL_STOP mode=DAMP` 让上位机同步状态。

**上位机脚本要求**：必须带周期心跳（≤200ms）并在退出时先 `#STOP`/`#DIS`；
断流时电机行为未知（见附录 A 实验 D），该实验结论决定是否要把心跳收紧到 100ms。

### 14.3 自审查发现并修掉的 3 个真 bug（实机前拦下）

1. **模式切换猛冲（安全问题）**：`#P/#V/#T/#IMP` 原先直接改 `mode`，`set_applied` 会保留上一模式的值（DAMP 时为 0）→ slew 从 0 起 → 与真实位置巨大 PD 误差 → 猛冲。**修复**：所有运动模式切换先经 `Ctrl_SetMode()` 把 `set_applied` 预置为**当前实际角/当前值**。已加静态断言锁定。
2. **`#V` 第 3 参误切模式**：原先用 `#IMP` 通道传前馈 → 会切到阻抗模式。**修复**：新增 `Ctrl_SetTff()`，前馈只加进速度环输出。
3. **畸形数字被静默吞掉**：`#V 1.2.3` / `#V 1e3` 会被当关键字接受（应报 `@ERR 2`）。**修复**：数字形状但解析失败的 token 一律 `CMD_PARSE_BADARG`（关键字必须字母/下划线开头）。由宿主机测试抓到。

另修：`Ctrl_Protect` 头声明漏 `t_nm`（编译期抓到）；`#GET` 超长行（0 警门禁抓到）。

### 14.4 已知边界（接受，不修）

- `Ctrl_Params_t` 由 CmdRx 写、控制任务读：单字段 32 位对齐是原子的；跨字段瞬时不一致（如 pmin/pmax 半更新）最坏影响一个控制周期，接受。
- `J8108_State()` 返回指针给 UI 只读显示：显示可能读到瞬时中间值（模式切换瞬间），仅影响画面，接受。
- 日志（`[tag]`）与协议行共用 USART6 且日志不走协议互斥锁：极端情况一行日志可能插入协议行中间；联调用 `#LOG 0` 基本消除（上位机应按"完整且以 @ 开头"过滤）。

### 14.9 v0.1.60 修复（静摩擦导致的「起步慢 + 黏滑抖动」，2026-09-18）

**实测**（`#V 10`，空载）：轴静止时需 **T≈0.25 N·m** 才起转；比例项只有 `KP_V·e = 0.003×10 = 0.03 N·m`；
`KI_V=0.0003` → 每秒仅攒 `0.003 N·m` → 攒到 0.25 需 **~80 秒**（日志实证：pos 停在 676.13° 达 6s 以上、T 从 0.03 爬到 0.26）；
动摩擦仅 ~0.1 N·m → 一动起来就平稳；期间 `vel` 4~18 dps 的纹波 = **黏滑振荡**。

**结论**：物理（库仑摩擦）问题，不是控制代码 bug。控制侧正解 = **前馈摩擦补偿**：

| 手段 | 说明 |
|---|---|
| `#SET TFF <N·m>`（新增） | **库仑摩擦前馈**：按速度设定点方向自动取号（+目标→+TFF，−目标→−TFF）；一次设定长期有效（`#V` 第 3 参的「一次性显式前馈」正交保留） |
| `#SET KI_V 0.02` | 积分快 60 倍 → 残余静差 1~2s 内补平 |
| `#SET TRATE 20` | 力矩斜率放开，能快速爬到摩擦量级 |

**推论（供带负载调参）**：静/动摩擦比 ≈ 2.5:1，故「空载都要 0.25 N·m 才起转」正常；带负载后 `TFF` 需重估（取 1Hz 日志 `T` 中位数）。

### 14.8 v0.1.58 加固（崩溃取证 / 栈裕量 / 协议口防锁死，2026-09-18）

实机 v0.1.55 出现"发完 `#LIM T 1` 后回包被切断在半句、后续命令全无响应"。**回包被切断 = 系统在发送过程中停止**（不是慢）——但当时无任何取证手段。三项加固：

| 项 | 做法 | 价值 |
|---|---|---|
| **崩溃黑匣子** | HardFault/栈溢出钩子在崩溃瞬间把 `PC/LR/CFSR`（或任务名）写进 **RTC 备份寄存器**（`mcu_bsp/sys_status/fault_log.{h,c}`）；`main` 开机读并打印后清标记 | **复位不清**（掉电才清）→ 免调试器拿到死因；.bss 的现场变量在复位后被启动代码清零，故不能只靠它 |
| **栈裕量自报** | `Task/Inc/stack_probe.h`：三个任务开机 5s 各打一行 `stack headroom: N words free of M`（`uxTaskGetStackHighWaterMark`，需 `INCLUDE_uxTaskGetStackHighWaterMark 1`） | STM32 无 MMU，栈溢出=静默踩内存；提前预警 + 事后可查 |
| **协议口不锁死** | `Proto_Send` 由 `portMAX_DELAY` 改为有界等待（50ms）+ 丢弃计数；计数进 10s 摘要 `txdrop=` | 单个任务卡住/崩溃不再让协议口永久静默（否则现场表现就是"板子卡死、连 `#STOP` 都发不进去"） |

另：CmdRx 栈 512→640 words（`b[256]` + `snprintf` 浮点 + 快照）。

**排查动线（用户侧）**：崩溃 → **按复位（别断电）** → 看 `[fault] E: PREVIOUS RUN CRASHED: ...` → 把整行发回。断了电就用 Keil 挂上、不复位，Watch `s_hf_pc` / `s_overflow_task`。

### 14.7 v0.1.55 修复（@EVT 刷屏 + #STAT 假数据，2026-09-18）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | `#SET KP_V 0.01` 后 `@EVT LIMIT what=torque` 刷屏 | 边沿锁存只挡得住**持续**受限；但力矩**斜率限制（TRATE）**会时紧时松地抖（某拍未受限 → 解锁 → 下拍又受限 → 再报）→ 200Hz 重报 | **消退去抖**：受限条件必须**连续消失 ≥1s**（`CTRL_EV_CLEAR_MS`）才允许把下一次受限算作新事件。同一抖动 episode 只报 1 条；真正的新 episode（中间正常 ≥1s）仍会报 |
| 2 | 使能前 `#STAT` 打出 `pos=-719.64 vel=-2578.3 T=-18.000 Tm=0 Tr=0` | **rx=0 时反馈缓冲全 0**，被当真值解算 → 恰好等于各量程最小值（±12.56rad→-720°、±45rad/s→-2578°/s、±18N·m） | `#STAT` 加新鲜度门控：不新鲜时只报 `link=DOWN ... age=never ... (values withheld)`；屏 P0 未收到过反馈显示 `AGE never` |

### 14.6 v0.1.54 修复（#V 抖动/不转，2026-09-18）

实机 `#V 20` 现象：**猛抖一下 → 200ms 后停**，日志 78ms 内刷几十条 `@EVT LIMIT`。两个独立原因：

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 只猛抖一下，不旋转 | `kp_v=0.05 N·m/(deg/s)` 对**小惯量直驱关节**过大：20 dps 误差 → 1 N·m；200Hz 下每 5ms 施加的力矩足以让关节加速上百 dps（`Δv≈(T/J)·dt`）→ 一个周期就冲过头 → 反向饱和 → **极限环震荡** | 默认改 `kp_v=0.005` / `ki_v=0.0005`；**新增力矩斜率限制** `trate_nm_s`（默认 20 N·m/s → 每周期 ≤0.1 N·m），从根上限制"每周期速度增量"；`#SET TRATE` 可调 |

| 3 | 停转 | **心跳语义**：`wd=200ms` 内无新命令即退 `DAMP`（防上位机失联，**设计行为**） | 文档化：台架测试先 `#WD 0`；真实运行由上位机按 ≤100ms 周期发命令 |

**调参铁律（已写进手册 §2.4）**：速度/位置模式**永远从小目标 + 小增益起**（`#V 5`、`#SET KP_V 0.002`），
并先用 `#LIM T 1` 当安全网；判据是"起步平滑 + 力矩不长期贴顶 + 无成片 `@EVT LIMIT`"。

## 附录 A · 定标实验步骤（用户执行）

### 实验 A：读电机配置串口的上电横幅（最直接）

1. **断电**。把电机 **SH1.0 6P** 配置口的 `V G T R` 接 USB-TTL：`V→3.3V`、`G→GND`、`T→TTL 的 RX`、`R→TTL 的 TX`（交叉）。
2. 用工具打开串口，**波特率必须 1,000,000（1Mbaud）8N1**：
   `python "D:\知识库\wiki-joint-motor\tools\8108_serial_tool.py" <COM口>`
3. **给电机上 24V 上电**，抄下打印的横幅（应含）：`板名` / `CANID` / `CANMODE` / `ControlMode` / **`Encoder:1|2`** / **`PMAX`** / `VMAX` / `TMAX`。
4. 需要确认命令通道可用时，发一条**无副作用**的写入（同值）：`CANID:0x01` → 应返回 `Set Success: CAN ID = 0x01 ...`。
5. **记录并判读**：`板名=`、`Encoder=`、`ControlMode=`、`PMAX=`、`VMAX=`、`TMAX=`

| 横幅显示 | 判读 | 协议口径 |
|---|---|---|
| `Encoder:2` + `PMAX:12.56` | **双编固件**（与文档一致） | 按 §3.2 **双编口径**（输出端、±12.56 rad） |
| `Encoder:1` | 单编固件（与文档不符） | 回退 §3.2 **兜底**（±25.12 电机端、÷8） |

6. **零工具快速核对（可选，你现在就能回答）**：当初手拧测试时我们显示 `15.2° → 53.3°`（变化约 **38°**）。
   若你当时其实拧了**约 40°** → 单编口径；若拧了**约 150°** → 双编口径（换算后 60.7° → 213.7°）。回忆一下即可初判。

### 实验 D（新，必做）：**控制流中断时电机的行为**

背景：电机是"一发一收"，一旦我们停止发帧（上位机崩、A 板复位、线掉），**电机是"保持最后一条命令持续出力"还是"自行保护归零"？文档没写**。
1. 使能后进 `DAMP`，确认数据流正常。
2. 发一条**小幅非零力矩**：`#T 0.5`（0.5 N·m，空载会缓慢加速，注意限速 `#LIM V 30`）。
3. **立刻停掉所有发帧**（拔 A 板上电/复位，或临时用 `#MODE IDLE`）。
4. 观察 10 秒：输出轴是**继续缓慢转动/持续出力**（= 保持最后命令，心跳必须严格）还是**自行停住/归零**（= 更安全）。
5. 记录结论 → 决定心跳阈值（200ms 或收紧到 100ms）与上位机退出流程（必须 `#STOP` + `#DIS`）。

### 实验 B：定标（1 整圈法 + 计时法）

**B1 位置口径**：在输出轴和机壳上各画一条对齐标记 →
1. 记下静止时 `#TEL 1` 的 `pos`（或日志 `fb#1 raw` 的原始码值）。
2. 用手**正好转 1 整圈**，回到标记对齐。
3. 记下 `pos` 与原始码值变化量：≈ **65535**（走满一圈）→ `SCALE_MODE=motor_side`；≈ **16384** → `output_side`。
4. 重复 3 次取平均（每次先记起点，避免累积误差）。

**B2 速度端别**：让输出轴**约 10 秒转 1 整圈**（用手机秒表）→ 看 `vel`：读≈**36 deg/s** = 输出端；读≈**288 deg/s**（=36×8）= 电机端。

**B3 方向**：按 B1 正转（顺时针看输出轴）时 `pos` **增大** → `DIR=+1`，减小 → `DIR=-1`。

### 实验 C（可选，验证双编能力）：原生模式是否可用

在实验 A 的配置串口上发 `ControlMode:1` → 若返回成功（且横幅/回显显示 `位置速度模式`），说明本机固件支持原生模式（二期可用）；**测完务必发 `ControlMode:0` 恢复 MIT 模式**（否则我们的 0x201 帧失效）。

## 附录 B · MIT 帧位映射（0x201，8 字节大端）

```
Byte0-1: p_des  (16 位)  量程 ±PMECH   ← §3.2
Byte2  : v_des[11:4]
Byte3  : v_des[3:0] | Kp[11:8]
Byte4  : Kp[7:0]
Byte5  : Kd[11:4]
Byte6  : Kd[3:0] | t_ff[11:8]
Byte7  : t_ff[7:0]

编码：raw = (x - min) × (2^bits - 1) / (max - min)    （线性映射，见双编文档 §3.2.2）
量程：p_des ±PMECH（**双编默认 ±12.56 rad**）· v_des ±45 rad/s · Kp 0~500 · Kd 0~5 · t_ff ±18 N·m
控制律：Tref = Kp(p_des - p) + Kd(v_des - v) + t_ff
```
> 文档警告（双编 §3.2.1）：`Kp=0,Kd≠0` → 匀速**有静差**、Kd 过大→震荡；`Kp≠0,Kd=0` → **震荡/失控**（故位置模式必须 Kp、Kd 成对给）。
