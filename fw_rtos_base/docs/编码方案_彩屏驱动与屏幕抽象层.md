## 0. 本轮输入（已锁定的事实，写代码时不许再改）

**决策快照**

| # | 决策 | 定案值 |
|---|---|---|
| D1 | 接口依据 | 商家**接口原理图**：8P = `VDD/GND/SDI/SCL/CS/SDO/RS/BLK`，**无 RST 脚** |
| D2 | 接线变体 | **A 变体**：`CS=PB10`、`SDO=PA6`、`BLK→3V3`（已实测悬空也常亮，仍建议接 3V3） |
| D3 | 汉字 | **板载字库芯片优先**（GB2312 12/16/24/32），内置点阵做兜底实现 |
| D4 | SPI 速率 | LCD 写 **10.5MHz**（APB2 84 ÷8）；读字库 **5.25MHz**（÷16） |
| D5 | DMA | 首版轮询；DMA2_Stream5_Ch3 版本用宏开关，跑通后再 A/B 对比 |
| D6 | 屏朝向 | **竖屏 128×160** |
| D7 | 界面文件名 | S1/S2 保留 `Task/Src/Oled_Task.c` 名，S3 之后再评估改名 |

**接线快照**（用户已完成，接线依据同 D1/D2）

| 屏 8P | 网络 | → A 板 OLED 口 | 端口脚 |
|---|---|---|---|
| 1 VDD | VDD | 3V3 | pin7 |
| 2 GND | GND | GND | pin6 |
| 3 SDI | MOSI | **PA7** | pin2 |
| 4 SCL | SCK | **PB3** | pin3 |

## 2. 分层与 include 规则（换屏零改动的**机制**保证）

```
Task/Src/Oled_Task.c   ← UI 页面层（4 页内容、门控、配色）
        │  只允许 include：disp_port.h + motor_8108.h + ui_status.h + version.h + ctrl_core.h
        ▼
mcu_bsp/disp/disp_port.h   ← 契约（本文件不含任何具体屏的符号）
        │  由 feature_config.h 的宏二选一，编译期选一个驱动进来
        ├── disp_sh1106_i2c.c   （#if FEATURE_DISP_SH1106_I2C）
        └── disp_st7735s_spi.c   （#if FEATURE_DISP_ST7735S_SPI）
                 │  两者都会 include disp_font.h / disp_geom.h（字体与算法共用）
                 ▼
        mcu_bsp/oled/OLED.c（旧）  |  SPI1 + GPIO（新）
```

**两条硬机制**（`verify_dev.py` 会检查，见 §9）：
1. **UI 层白名单**：`Oled_Task.c` 里出现 `OLED_`、`HAL_`、`SPI1`、`GPIO` 等私有符号即 FAIL → 保证"换屏不改页面"不是靠自觉。
2. **未选中的驱动整文件被宏包住**：Keil 会编译所有加进工程的文件，两个驱动都实现 `Disp_Init` 等符号会**重复定义**。所以每个驱动 `.c` 从第一行到末行都被 `#if FEATURE_DISP_xxx ... #endif` 包住，未选中时编译成**空对象**（Keil 允许，链接无冲突）。

## 3. 契约层精确规格（`disp_port.h`）

```c
/* 字号档位（页面层只认这三档；驱动负责映射到实际点阵） */
typedef enum { DISP_FONT_SMALL = 0, DISP_FONT_MED = 1, DISP_FONT_BIG = 2 } Disp_Font_e;

typedef struct {
    const char *name;              /* "SH1106-I2C" / "ST7735S-SPI"，开机日志用 */
    uint16_t w, h;                 /* 逻辑分辨率（当前朝向），竖屏=128x160 */
    uint8_t  color_bits;           /* 1=单色, 16=RGB565 */
    uint8_t  font_w[3], font_h[3]; /* SMALL/MED/BIG 的字符格尺寸（页面层排版用） */
    uint8_t  has_brightness;       /* 是否支持 Disp_Brightness */
    uint8_t  has_cn;               /* 是否支持 Disp_TextCn（汉字） */
} Disp_Info_t;

/* 主题色（RGB565 值；单色驱动把"非 0"视为点亮） */
#define DISP_C_BG   0x0000u   /* 背景：黑 */
#define DISP_C_FG   0xFFFFu   /* 正文：白 */
#define DISP_C_OK   0x07E0u   /* 正常/已建立：绿 */
#define DISP_C_WARN 0xFFE0u   /* 预警/限幅：黄 */
#define DISP_C_ERR  0xF800u   /* 错误/断链/急停：红 */
#define DISP_C_DIM  0x8410u   /* 单位/提示：灰 */

void               Disp_Init(void);                 /* 幂等；自带 GPIO/AF/SPI 初始化；调度器启动前可调用 */
const Disp_Info_t *Disp_Info(void);                 /* 永不为 NULL；初始化失败时 w/h 置 0 → UI 层自动降级为空操作 */
void Disp_Clear(uint16_t color);
void Disp_FillRect(int16_t x, int16_t y, int16_t w, int16_t h, uint16_t color);
void Disp_Text(int16_t x, int16_t y, const char *s, uint16_t fg, uint16_t bg, Disp_Font_e sz);
void Disp_TextCn(int16_t x, int16_t y, const char *gb2312, uint16_t fg, uint16_t bg, Disp_Font_e sz); /* 不支持时静默不画 */
void Disp_Line(int16_t x0, int16_t y0, int16_t x1, int16_t y1, uint16_t color);
void Disp_Rect(int16_t x, int16_t y, int16_t w, int16_t h, uint16_t color, uint8_t filled);
void Disp_Flush(void);                              /* 唯一"上屏"动作 */
void Disp_Brightness(uint8_t pct);                  /* 不支持则空实现 */
uint8_t Disp_SelfTest(void);                        /* 0=OK；初始化阶段调用一次，结果进日志 */
```

**语义（写进头文件注释，作为以后争议的裁判）**

| 约定 | 内容 |
|---|---|
| 坐标 | 原点左上；`x∈[0,w)`、`y∈[0,h)`；**越界自动裁剪**（驱动内部钳位，不崩） |
| 颜色 | 彩色屏 = RGB565；单色屏 = `color != 0` 即点亮。页面层只用 `DISP_C_*`，不写裸值 |
| 刷新 | 画图只改显存/脏区；**`Disp_Flush()` 才上屏**；驱动自选策略（单色=页推、彩屏=脏矩形行带） |
| 时间预算 | 单次调用 <5ms（Monitor 是 prio3）；**禁止 `vTaskDelay`、禁止无界自旋** |
| 调用者 | `Disp_Init/SelfTest` 在 `main()`（调度器前）；其余只在 Monitor 任务里调 → 无并发 |
| 失败降级 | `Disp_Info()->w == 0` → UI 层所有绘制变成空操作（屏坏了系统照跑） |

## 5. 驱动 B：`disp_st7735s_spi.c`（S2/S3 · 主体）

### 5.1 初始化（严格按此顺序，顺序本身就是坑）

| 步 | 动作 | 为什么/坑 |
|---|---|---|
| 1 | `__HAL_RCC_GPIOA/GPIOB_CLK_ENABLE()` | 都在 AHB1 |
| 2 | **`__HAL_AFIO_REMAP_SWJ_NOJTAG()`** | PB3 默认归 JTDO；**必须早于配 PB3**，且只能关 JTAG（SWD 保留，否则下载器失联） |
| 3 | PB3/PA7/PA6 = `AF5`（SPI1），PB9(RS)/PB10(CS) = 推挽输出；**先把 CS 拉低** | CS 高 = 选中字库芯片 → 初始化前必须先把 LCD 选回来 |
| 4 | `SPI1` 配置：MSTR=1、8bit、CPOL=0/CPHA=0、MSB first、`SSM=1`+`SSI=1`（软件 NSS，防 MODF）、BR=`÷8`(10.5MHz)、**双工（保留 MISO 以读字库）** | 用 `HAL_SPI_Init`；不落进 CubeMX 生成区 |
| 5 | 上电稳定等待 **≥120ms**（DWT 忙等，不依赖中断/SysTick） | 与 `OLED.c:110` 同一套 DWT 延时（调度器前 `HAL_Delay` 会卡死，有实机教训） |
| 6 | `0x01 SWRESET` + 等 120ms | 模块没有 RST 脚，软复位是唯一复位手段 |
| 7 | 初始化序列（照抄例程）：`0x11`+120ms → `0xB1/B2/B3` 帧率 → `0xB4` → `0xC0/C1/C2/C3/C4/C5` 电源 → `0x36` 朝向 → `0xE0/E1` gamma → `0x3A=0x05`(65k) → `0x29` | 出处：模块官方例程 `lcd_init.c` |
| 8 | 朝向 + **坐标偏移标定**：竖屏 `MADCTL=0x00`；偏移 `XSTART/YSTART` 先取 `0/0`，用自检画面验（常见另有 `0/24`、`24/0`） | 不同批次玻璃的偏移不同，只能实测定标 |
| 9 | `Disp_Clear(DISP_C_BG)` + `Disp_SelfTest()` | 开机第一屏：边框 + 四角色块 + 中心十字 + 三色条 + 版本号文字 |

### 5.2 显存与刷新策略

- **显存**：`static uint16_t s_fb[128*160];` = **40,960 B**（普通 `.bss`，`.sct` 的 `RW_IRAM1` 192KB 装得下；RAM 预算见 §12）。
- **脏区**：`disp_geom.c` 里做纯逻辑记账——`Disp_Dirty(int16_t x,int16_t y,int16_t w,int16_t h)` 求并集；面积超过 `DISP_DIRTY_FULL_RATIO`（默认 40%）→ 升级为整屏。
- **上屏**：按**行带**切（默认 16 行）→ 每带：`0x2A/0x2B` 设窗口 → `0x2C` → 连推 `w*16*2` 字节 → 全程 **CS 保持低**（CS 抬高会把数据写进字库芯片！）。
- **发送**：首版 `HAL_SPI_Transmit(&hspi1, buf, n, 20)`；DMA 版（`DISP_USE_DMA=1`）用 **DMA2_Stream5/Ch3** + 完成信号量（已核对不撞 USART6_RX/SDIO）。
- **测速埋点**：`Disp_Flush()` 前取 DWT 周期、后取差 → `s_last_flush_us`；开机自检与 10s 摘要打 `flush=…us`（判据见 TM-D2）。
- **预算核对**（10.5MHz）：一页整行带 `160×16×2B=5120B ≈ 3.9ms`；全屏 `≈31ms`（只在整屏清屏时发生）。

### 5.3 原语要点

| 原语 | 实现要点 |
|---|---|
| `Disp_FillRect` | 按写"行"填 `s_fb`（`for y` 内 `memset`/循环写 `uint16_t`）；同时 `Disp_Dirty()` |
| `Disp_Text` | 取字模（§6）→ 逐列展开（纵向 8 点/字节，**LSB 在上**）→ 每像素写 `fg/bg` 到 `s_fb`；同时 `Disp_Dirty()` |
| `Disp_TextCn` | 字库取模（§6）→ 16 或 24 或 32 点阵逐位展开 |
| `Disp_Line` | Bresenham（**自己实现纯函数版**放 `disp_geom.c`，可宿主机测试；算法与 `OLED.c:982` 同源便于对照） |
| `Disp_Rect` | 边框 4 条线；填充走 `FillRect` |

## 6. 字体层：`disp_font.c`（S2 小字 / S4 汉字+大字）

### 6.1 ASCII 两个来源（各有用途）

| 来源 | 字号 | 用途 | 备注 |
|---|---|---|---|
| **内置点阵**（复用现成 `OLED_Data.c` 的 `OLED_F6x8`(95×6B) 与 `OLED_F8x16`(95×16B)） | 6×8 / 8×16 | 界面行文本（每帧都在刷） | **零 ROM 读取、零延迟、零缓存**；索引 `ch - 0x20` |
| **板载字库 ROM** 的 ASCII 表 | 5×7 / 7×8 / 6×12 / **12×24** / **16×32** | 大字实时数值（POS/VEL/T） | 地址 = `(ch-0x20)*n + BaseAdd`；BaseAdd 见下表 |

**字库 ASCII 基址（取自例程 `zk.c`，实测值）**

| 字号 | BaseAdd | n(字节/字) |
|---|---|---|
| 5×7 | `0x1DDF80` | 8 |
| 7×8 | `0x1DE280` | 8 |
| 6×12 | `0x1DBE00` | 12 |
| 8×16 | `0x1DD780` | 16 |
| **12×24** | `0x1DFF00` | 48 |
| **16×32** | `0x1E5A50` | 64 |

### 6.2 汉字（GB2312）

```
读事务（disp_font.c 内唯一出口，封装成 read_glyph()）：
  ① CS = 1            → 选中字库芯片
  ② SPI 写 0x03 + A16 + A8 + A0
  ③ SPI 读回 n 字节（n = 24/32/72/128，按字号）
  ④ CS = 0            → 选回 LCD   ← 漏了这步 = 花屏
地址：标点区 Addr = ((MSB-0xA1)*94 + (LSB-0xA1)) * n + BaseAdd
      汉字区 Addr = ((MSB-0xB0)*94 + (LSB-0xA1) + 846) * n + BaseAdd
BaseAdd：12×12→0x000000  16×16→0x02C9D0  24×24→0x068190  32×32→0x0EDF00
```

- **缓存**：`CnCache[24]`，每项 `{uint16_t gb; uint8_t size; uint8_t used; uint8_t bmp[128];}` ≈ **3.2KB**；命中直接返指针，未命中读 ROM 后按环形替换。界面固定文案（"位置/速度/力矩/温度/状态/链路"…）第一屏就全进缓存。
- **兜底**：读回全 `0x00`/全 `0xFF` → 判定字库不可用 → 置 `Disp_Info()->has_cn=0` + 打一条 E 日志（英文），界面自动回落到英文标签；`FEATURE_DISP_CN_INTERNAL=1` 时改走"内置点阵"实现（同一 `Disp_TextCn`，编译期二选一）。
- **编码口径**：页面层字符串必须是 **GB2312**（源文件保存为 GB2312 或写成 `"\xCE\xBB\xD6\xC3"` 转义）；避开 GBK 扩展字。

## 7. UI 层改造规格（`Task/Src/Oled_Task.c`）

**保持不变（回归判据）**：
1. 4 页结构与字段（P0 LINK / P1 MOTION / P2 SERIAL / P3 SYSTEM）；
2. `rfmt()` 的"逐行比对、无变化不刷"；
3. 数据门控：`rx_count==0` → `AGE never  LINK DOWN`；`age≥200ms` → `LINK DOWN`（**逐字保留**，既有断言在查）；
4. 按键行为（单击翻页/双击上页/长按回 P0）—— 本文件不碰按键逻辑。

**改动点（逐处）**：

| 现在 | 改成 |
|---|---|
| `OLED_Clear()` | `Disp_Clear(DISP_C_BG)` |
| `OLED_ShowString(0, row*8, out, OLED_6X8)` | `Disp_Text(0, row*line_h, out, color, DISP_C_BG, sz)`，`line_h` 取自 `Disp_Info()` |
| `OLED_Update()` | `Disp_Flush()` |
| 21 列 × 8 行硬编码 | 由 `Disp_Info()->w/h/font_*` 算出列数与行高（**同一份代码在 128×64 单色与 128×160 彩色上都能排**） |

**竖屏 128×160 建议布局（S3 实施，先按 8×16 字体）**：16 列 × 10 行（行高 16px，顶部留 0px，底部 0px），P1 页把 `POS/VEL/T` 三个数值换成 **12×24 字库大字**（约 60px 宽的数值区）。
**颜色规范**：正常=白；`LINK UP`/`INPOS`=绿；`WARN`（温度预警、`LIMIT`）=黄；`ERR`/`LINK DOWN`/`ESTOP`=红；单位与提示行=灰。**门控时段（不新鲜）一律灰/红，绝不显示旧数值。**

## 13. 编码层面的 6 个小决策（请你点头，我按建议执行）

| # | 决策 | 建议 | 影响 |
|---|---|---|---|
