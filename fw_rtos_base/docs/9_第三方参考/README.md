## 使用约定

1. **只用结论，不搬代码**：厂商例程用于理解时序/协议；真正驱动由本项目自己实现（契约头 + 文件级宏 + 断言），见 `docs/1_规则（既定事实）/规范_功能宏与模块化.md`。
2. **结论必须落纸**：任何从第三方资料得出的关键判断（引脚、时序、地址、量程）都要写进 `1_规则/` 或 `2_方案/` 文档，并注明来源文件；**禁止只存在于聊天记录里**。
3. **冲突时以实物/实测为准**：商家文档错过一次（把 8P 的第 6 脚标成 RST，实际是字库 SDO）—— 接口原理图 + 实测 > 商家说明表。
4. **不进版本库的大文件**：如需长期保存，放 `外部参考资料/`（已被忽略）；不要复制进 `fw_rtos_base/`。
